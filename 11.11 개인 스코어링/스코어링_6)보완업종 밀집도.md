# 스코어링 6) 보완업종 밀집도

매물 주변 300m 안의 가게 중에서 **이 업종과 함께 있으면 손님을 나눠 주는 업종(보완업종)**이 얼마나 많은 비율을 차지하는지 보고 점수를 줍니다.

- 적용 카테고리: 식당, 카페, 술집, 소매, 오피스, 전시
- 데이터: 소상공인시장진흥공단 상가(상권)정보 대구 (2026)
  `데모/추가 자료/소상공인시장진흥공단_상가(상권)정보-대구/[원본1]상가정보_대구전체(2026).xlsx` (118,357곳)
- 동일업종 밀집도와 같은 파일이고, 세는 업종만 다릅니다.

## 2. 카테고리별 보완업종 목록

### 고른 방법

상가정보로 6개 카테고리 가게마다 주변 300m에 어떤 업종이 **대구 평균보다 더 많이 모여 있는지** 계산했습니다.

- 처음 계산에서는 시계·귀금속, 옷가게, 여행사, 사진관이 6개 카테고리 모두 상위에 나왔습니다. 이는 서로 손님을 나눠 주는 관계가 아니라 **동성로 같은 번화가에 모든 업종이 같이 모여 있어서** 생긴 결과입니다.
- 그래서 **그 카테고리 주변에만 특히 더 모이는 업종**을 다시 뽑았습니다 (예: 노래방은 술집 주변에서만 유난히 많음).
- 위치가 우연히 겹쳐서 나온 업종은 뺐고, 꼭 필요한데 데이터에 안 잡힌 업종은 판단으로 1개만 더했습니다.

- **오피스에 점심 식당·카페를 넣지 않은 이유:** 식당·카페는 어디에나 많아서 오피스 주변에만 특별히 더 많지 않고, 매물 간 차이를 만들지 못합니다.
- **믿을 만한 정도:** 술집·카페 ◎, 소매·오피스 ○, 식당·전시 △ (식당은 어디에나 있어 짝이 약하고, 전시는 갤러리가 적음). 다만 3·5번처럼 공실 매물에 적용한 결과는 6개 모두 상식과 맞았습니다.
- **주의:** "같이 모여 있다"가 꼭 "서로 손님을 나눠 준다"는 뜻은 아닙니다.

## 3. 계산 방법

```
보완업종 비율 = 매물 300m 안 보완업종 가게 수 ÷ 매물 300m 안 전체 가게 수
```

- **원의 크기:** 300m (동일업종 밀집도의 식당·카페·술집·소매와 같은 거리)
- **개수가 아니라 비율을 쓰는 이유:** 보완업종 **개수**는 가게가 많은 동네일수록 그냥 많아집니다. 전체 가게 수와의 상관계수가 0.53~0.89로 높아서, 결국 "가게가 많은 동네인가"를 보는 것과 거의 같아집니다. **비율**로 보면 상관계수가 대부분 0.2 아래(카페만 0.49)로 떨어져서, "가게가 많냐"가 아니라 **"이 업종과 잘 맞는 가게가 많은 동네냐"**만 남습니다.

| 카테고리 | 개수와 전체 가게 수의 상관 | 비율과 전체 가게 수의 상관 |
|---|---|---|
| 술집 | 0.76 | 0.14 |
| 식당 | 0.67 | 0.17 |
| 카페 | 0.84 | 0.49 |
| 소매 | 0.89 | 0.11 |
| 오피스 | 0.53 | −0.02 |
| 전시 | 0.86 | 0.08 |

- **판단 보류 (50점):** 매물 주변 300m 안 전체 가게가 **30곳 미만**이면, 가게 몇 곳만 바뀌어도 비율이 크게 흔들리므로 중간 점수 50점을 줍니다. 해당 매물은 21곳(0.8%)입니다.
  - 화면 표시: "주변 가게가 적어서 보완업종 점수를 중간(50점)으로 표시했어요"

- 첫 칸(10점)보다 낮으면 **0점**, 100점 칸 이상(상위 10%)이면 **100점**입니다. 90점은 쓰지 않습니다.
- 카테고리마다 퍼센트가 다른 이유: 보완업종으로 세는 업종의 수가 카테고리마다 달라서, 같은 카테고리 매물끼리만 비교합니다.

## 7. 참고 사항

- **보완업종 목록은 데이터와 판단을 섞어 정했습니다.** 특히 식당·전시는 데이터의 짝이 약해서, 나중에 실제 매출이나 개업 성과 데이터가 생기면 다시 확인합니다.
- **상가정보에는 은행 같은 금융업이 없어서** 오피스의 "은행 근처" 같은 건 볼 수 없습니다.
- **카페는 비율과 전체 가게 수의 상관이 0.49로 다른 카테고리보다 높습니다.** 카페는 주변 가게가 많은 동네일수록 보완업종 비율도 조금 높게 나오는 경향이 있습니다.
- **새 상가정보 파일을 받으면** 점수 변환표를 다시 만듭니다.
