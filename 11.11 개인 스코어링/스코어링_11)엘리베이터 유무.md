# 스코어링 11) 엘리베이터 유무

매물이 있는 건물에 **엘리베이터가 있는지**와 **매물의 층**을 보고 점수를 줍니다. 위층 매물일수록 엘리베이터가 없으면 손님과 직원이 오가기 어렵기 때문입니다.

- 적용 카테고리: 오피스, 전시 (나머지 카테고리는 가중치 0%)
- 데이터
  - 국토교통부 건축물대장 **표제부** (대구, 2026년 9월 기준)
    `데모/추가 자료/대구 주차정보 데이터/건축물대장_표제부_대구광역시(2026년09월).csv`
    - 사용하는 칸: 총승강기수(승용 + 비상용), PNU(필지 번호)
  - 국토교통부 건축물대장 **부속지번** (대구, 2026년 9월 기준)
    `데모/추가 자료/대구 주차정보 데이터/건축물대장_부속지번_대구광역시(2026년09월).csv`
  - 국토교통부 **토지특성정보** (필지 경계, 2026년 5월 기준)
    `데모/추가 자료/대구 토지특성정보/`
  - 대구 구역별 공실 매물 CSV (매물 좌표, 층)
    `데모/추가 자료/대구 전체 공실정보/대구_구역별_매물 (최종).csv`
- 건축물대장은 2026년 9월 기준이라, 그 뒤에 설치된 엘리베이터는 반영되지 않습니다.

## 1. 카테고리별 가중치 (100점 만점 기준)

| 카테고리 | 엘리베이터 유무 가중치 | 이유 |
|---|---|---|
| 오피스 | 15% | 위층 사무실이 많고, 직원·방문객이 매일 오르내립니다 |
| 전시 | 5% | 위층 갤러리는 관람객이 엘리베이터로 올라옵니다 |
| 술집, 식당, 카페, 소매 | 0% | 대부분 1~2층이라 영향이 작습니다 |

## 2. 점수

| 매물 층 | 엘리베이터 있음 | 엘리베이터 없음 |
|---|---|---|
| 1층, 전체층 | **100** (확인하지 않음) | **100** |
| 지하 | 100 | **70** |
| 2층 | 100 | **70** |
| 3층 | 100 | **40** |
| 4~5층 | 100 | **20** |
| 6층 이상 | 100 | **0** |

- **1층은 엘리베이터가 필요 없으므로** 엘리베이터 유무와 상관없이 100점입니다.
- **엘리베이터 판단:** 건축물대장 표제부의 총승강기수(승용 + 비상용)가 1대 이상이면 "있음"입니다. 대수는 보지 않습니다.
- **한 필지에 건물이 여러 개면** 그중 하나라도 엘리베이터가 있으면 "있음"으로 봅니다 (매물이 어느 동에 있는지 알 수 없기 때문입니다).

## 3. 건물을 찾는 순서

매물 좌표로 건축물대장의 건물을 아래 순서로 찾습니다.

| 순서 | 방법 | 설명 |
|---|---|---|
| ① | 필지 번호로 찾기 | 매물 좌표가 들어 있는 필지(토지특성정보)의 번호(PNU)로 표제부를 찾습니다 |
| ② | 부속지번으로 찾기 | ①에서 없으면, 부속지번에서 "이 필지에 걸쳐 있는 건물"을 찾습니다. 큰 건물이 여러 필지에 걸쳐 있고 대표 번지가 다른 경우입니다 |
| ③ | 옆 필지로 찾기 | ②에서도 없으면, 매물 좌표에서 **20m 안**에 있는 필지 중 건물이 등록된 **가장 가까운 필지**의 엘리베이터 수를 씁니다. 매물 좌표가 건물 옆 도로나 경계선에 찍힌 경우입니다 |
| ④ | 판단 보류 | ①~③으로도 찾지 못하면 판단 보류(50점)입니다 |

- ③ 옆 필지로 찾은 값은 추정입니다. 거리가 멀수록 바로 옆 다른 건물을 잡았을 가능성이 있습니다.

## 4. 판단 보류 (50점)

| 경우 | 점수 |
|---|---|
| 층이 불명확한 매물 ("기타") | 50점 |
| 2층 이상·지하 매물인데 ①~③으로 건물을 찾지 못함 | 50점 |

- 화면 표시: "건물 정보가 없어서 엘리베이터 점수를 중간(50점)으로 표시했어요"

## 5. 최종 반영 점수

```
최종 반영 점수 = 엘리베이터 점수 × 카테고리별 가중치
```

## 6. 참고 사항

- **층별 "없음" 점수(70 / 40 / 20 / 0)는 판단으로 정한 값입니다.** 2층은 계단으로도 많이 다니고, 층이 높을수록 계단으로 올라오는 손님이 크게 줄어든다는 생각으로 정했습니다.
- **엘리베이터 대수는 보지 않습니다.** 1대인 작은 건물과 여러 대인 큰 업무 빌딩이 같은 점수입니다.
- **새 건축물대장을 받으면** 다시 연결합니다.
