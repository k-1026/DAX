# 스코어링 8) 노출&가시성

매물이 있는 필지가 **어떤 도로에, 몇 면이 붙어 있는지(도로접면)**와 **매물의 층**을 보고, 길에서 눈에 잘 띄는 자리인지 점수를 줍니다.

- 적용 카테고리: 식당, 카페, 술집, 소매, 오피스, 전시
- 데이터
  - 국토교통부 토지특성정보 (2026년 5월 기준, 필지별 공간정보)
    `데모/추가 자료/대구 토지특성정보/대구_OO구_토지특성공간정보_SHP/` (구·군별 9개 폴더)
    - 사용하는 칸: 도로접면(A24), 필지 경계(공간정보)
  - 대구 구역별 공실 매물 CSV (매물 좌표, 층)
    `데모/추가 자료/대구 전체 공실정보/대구_구역별_매물 (최종).csv`

## 1. 카테고리별 가중치 (100점 만점 기준)

| 카테고리 | 노출&가시성 가중치 | 이유 |
|---|---|---|
| 소매 | 20% | 눈에 보여야 들어오는 업종이라 가장 중요합니다 |
| 식당 | 15% | 지나가다 들어오는 손님이 많습니다 |
| 카페 | 15% | 눈에 띄는 자리가 손님을 끌어옵니다 |
| 술집 | 10% | 2층·지하 술집도 간판이 잘 보여야 손님이 찾아옵니다 |
| 오피스 | 5% | 손님이 찾아오는 업종이 아니라 영향이 작습니다 |
| 전시 | 5% | 관람객이 일부러 찾아오는 경우가 많아 영향이 작습니다 |

## 2. 계산 방법

```
노출 점수 (0~100) = 도로접면 점수 × 층 보정
최종 반영 점수     = 노출 점수 × 카테고리별 가중치
```

- 매물 좌표가 들어 있는 필지를 토지특성정보(공간정보)에서 찾아, 그 필지의 도로접면을 씁니다.

## 3. 도로접면 점수

**도로 폭**을 먼저 보고, 같은 폭이면 **코너(각지)**에 10점을 더 줍니다.

| 도로접면 | 뜻 | 점수 |
|---|---|---|
| 광대소각 | 폭 25m 이상 큰길 + 작은 길(소로) 코너 | **100** |
| 광대세각 | 폭 25m 이상 큰길 + 골목(세로) 코너 | **95** |
| 광대로한면 | 폭 25m 이상 큰길에 한 면 | **90** |
| 중로각지 | 폭 12~25m 도로 코너 | **80** |
| 중로한면 | 폭 12~25m 도로에 한 면 | **70** |
| 소로각지 | 폭 8~12m 도로 코너 | **60** |
| 소로한면 | 폭 8~12m 도로에 한 면 | **50** |
| 세로각지(가) | 폭 8m 미만 골목 코너, 차가 들어감 | **35** |
| 세로한면(가) | 폭 8m 미만 골목에 한 면, 차가 들어감 | **25** |
| 세로각지(불) | 폭 8m 미만 골목 코너, 차가 못 들어감 | **15** |
| 세로한면(불) | 폭 8m 미만 골목에 한 면, 차가 못 들어감 | **10** |
| 맹지 | 도로에 붙어 있지 않음 | **0** |

## 4. 층 보정

같은 큰길 코너 건물이라도 위층일수록 지나가는 사람 눈에 덜 띕니다.

| 층 | 보정 | 이유 |
|---|---|---|
| 1층, 전체층 | × 1.0 | 길에서 바로 보입니다 |
| 2층, 기타(층이 불명확) | × 0.7 | 간판은 보이지만 가게 안은 보이지 않습니다 |
| 3~5층 | × 0.5 | 간판만 보입니다 |
| 지하 | × 0.5 | 입구만 보입니다 |
| 6층 이상 | × 0.3 | 거의 보이지 않습니다 |

## 5. 따로 처리하는 매물

| 경우 | 처리 |
|---|---|
| 매물이 있는 필지에 도로접면 값이 비어 있음 (주로 새로 지은 대단지 상가) | **20m 안의 가장 가까운 옆 필지**의 도로접면을 빌려 씁니다 (공실 매물 446곳) |
| 20m 안에도 도로접면 값이 있는 필지가 없음 | **판단 보류 50점** (공실 매물 20곳) |

- 판단 보류 화면 표시: "도로 정보가 없어서 노출 점수를 중간(50점)으로 표시했어요"
- 옆 필지로 채운 값은 추정입니다. 대단지 상가는 단지 안쪽 상가일 수도 있어서, 옆 필지가 큰길에 붙어 있어도 실제 매물은 안쪽일 수 있습니다.

## 6. 참고 사항

- **도로접면은 필지(땅) 기준입니다.** 큰 건물이 큰길에 붙어 있어도 매물이 건물 뒤쪽이면 실제로는 잘 보이지 않는데, 이 데이터로는 알 수 없습니다.
- **보행자 거리는 낮게 나옵니다.** 도로접면은 차도 폭 기준이라, 동성로처럼 사람만 다니는 보행자 거리는 "좁은 골목(세로)"으로 잡힙니다 (예: 중구 삼덕동1가 공실 매물 17곳 중 6곳이 세로한면). 이 기준은 "길에서 눈에 잘 띄는 자리인가"만 보고, 사람이 얼마나 지나다니는지는 보지 않습니다.
  - 보완이 필요하면: 토지특성정보의 용도지역(중심상업지역 등)을 이용해, 상업지역 안의 세로·소로 필지 점수를 올려 주는 방법이 있습니다 (아직 적용하지 않음).
- **매물 설명과 잘 맞습니다:** 매물 설명에 "코너"가 적힌 282곳 중 79%가 실제로 각지(코너) 필지였습니다.
- **새 토지특성정보를 받으면** (매년 갱신) 다시 연결합니다.
