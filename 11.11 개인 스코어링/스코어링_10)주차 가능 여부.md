# 스코어링 10) 주차 가능 여부

매물이 있는 **건물에 손님이 직접 차를 댈 수 있는 주차 칸이 몇 대인지** 보고 점수를 줍니다. 건물 주차가 부족해도 근처에 공영·민영 주차장이 있으면 점수를 조금 올려 줍니다.

- 적용 카테고리: 식당, 카페, 소매, 오피스, 전시 (술집은 0%)
- 데이터
  - 건축물대장 표제부 (국토교통부, 2026년 9월)
    `데모/추가 자료/대구 주차정보 데이터/건축물대장_표제부_대구광역시(2026년09월).csv`
  - 전국주차장정보표준데이터 대구 (2026년 4~10월 기준)
    `데모/추가 자료/대구 주차정보 데이터/전국주차장정보표준데이터_대구광역시.csv`

## 1. 카테고리별 가중치 (100점 만점 기준)

| 카테고리 | 주차 가중치 | 이유 |
|---|---|---|
| 술집 | 0% | 술을 마시면 운전을 못 해서 손님이 차를 가져오지 않습니다 |
| 식당 | 10% | 가족 외식·저녁 손님은 차로 오는 경우가 많습니다 |
| 카페 | 5% | 대부분 걸어오지만, 차로 찾아오는 손님도 일부 있습니다 |
| 소매 | 10% | 물건을 사서 들고 가야 해서 차가 있으면 편합니다 |
| 오피스 | 15% | 직원 출퇴근과 거래처 방문에 주차가 꼭 필요합니다 |
| 전시 | 5% | 관람객 일부가 차로 옵니다 |

## 2. 무엇을 세나

건축물대장 표제부의 주차 대수 4종 중 **자주식만** 더합니다.

| 항목 | 셈 |
|---|---|
| 옥내 자주식 대수 (건물 안, 직접 운전해서 대는 칸) | ✓ 셈 |
| 옥외 자주식 대수 (건물 밖 마당) | ✓ 셈 |
| 옥내 기계식 대수 | ✗ 뺌 |
| 옥외 기계식 대수 | ✗ 뺌 |

- **기계식을 빼는 이유:** 기다려야 하고 큰 차는 못 들어가서 손님이 실제로 쓰기 어렵습니다.
- **대수를 그대로 쓰는 이유:** 손님 입장에서는 "차 댈 데가 있나"가 중요하고, 설명하기 쉽습니다.

## 3. 매물과 건물 연결하기

건축물대장에는 좌표가 없고 매물에는 번지가 없어서, 아래 네 가지가 **모두 같은 건물**을 찾습니다.

```
매물의 구 = 건물의 구
매물의 법정동 = 건물의 법정동
매물의 사용승인일 = 건물의 사용승인일
매물의 전체 층수 = 건물의 지상 층수
```

- 주건축물만 봅니다. 창고·차고 같은 부속건축물은 뺍니다.
- **후보 건물이 여러 개일 때:** 후보들의 자주식 대수가 모두 같으면 그 값을 쓰고, 다르면 판단 보류(50점)로 둡니다.
- **연결된 건물이 아파트(공동주택)일 때:** 단지 주차장은 입주민용이라 상가 손님이 쓰기 어렵습니다. 판단 보류(50점)로 둡니다.
- **건물을 못 찾을 때:** 판단 보류(50점)로 둡니다.

## 4. 점수 변환표

**① 건물 주차 점수**

| 자주식 주차 대수 | 점수 |
|---|---|
| 0대 | 10점 (가중치의 0.1배) |
| 1~4대 | 40점 |
| 5~12대 | 60점 |
| 13~46대 | 80점 |
| 47대 이상 | 100점 |

**② 주변 주차장 가산점**

- 조건: ① 점수가 **60점 미만**(0대, 1~4대)이고, 매물 **300m 안에 노외 주차장**이 1곳 이상 있을 때
- 가산: **+20점**, 단 최대 **60점**까지만
  - 0대 → 10점 + 20점 = **30점**
  - 1~4대 → 40점 + 20점 = **60점**
- 노외 주차장은 공영과 민영을 모두 셉니다.
- **노상(길가) 주차장은 뺍니다.** 잠깐 대는 용도라 손님 주차로 보기 어렵습니다.
- **가산점만 주고 감점은 없습니다.** 구청마다 주차장 데이터를 올린 양이 크게 달라서(예: 북구 264곳, 수성구 31곳), 주차장이 없다고 깎으면 데이터가 적은 구 매물이 억울하게 낮아집니다.
- 판단 보류(50점) 매물에는 가산점을 주지 않습니다.

**③ 최종 반영 점수**

```
최종 반영 점수 = (① + ②) × 카테고리별 가중치
```

## 5. 참고 사항

- **판단 보류 (50점):** 건물을 못 찾은 매물, 후보 건물이 여러 개인데 주차 대수가 서로 다른 매물, 아파트 단지 안 상가는 50점으로 둡니다. 화면에는 아래 문구를 함께 표시합니다.
  > 건물 정보를 찾지 못해 주차 점수를 중간(50점)으로 표시했어요
- **연결 정확도:** 건물명을 비교할 수 있는 매물로 확인했을 때, 대부분 같은 건물이었고 이름 표기만 달랐습니다(예: JJ빌딩 / J&J빌딩). 다른 건물로 잘못 연결된 경우는 소수였습니다.
- **새 건축물대장이나 새 주차장 데이터를 받으면** 연결과 점수를 다시 계산합니다.
