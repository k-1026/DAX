# 스코어링 5) 임대료 적정성

매물의 **㎡당 월세**를 **같은 층·비슷한 크기·가까운 다른 공실 매물**과 비교해서, 주변보다 싸면 높은 점수를 줍니다.

- 적용 카테고리: 식당, 카페, 술집, 소매, 오피스, 전시 (6개 모두 같은 기준)
- 데이터: 대구 구역별 공실 매물 CSV
  `데모/추가 자료/대구 전체 공실정보/대구_구역별_매물 (최종).csv`
  - 사용하는 칸: 월세, 전용면적, 층, 구, 경도·위도
- 상가 임대료 실거래가는 공개되지 않아서, **공실 매물끼리 비교**합니다. 매물 가격은 계약가가 아니라 내놓은 가격(호가)이지만, 모든 매물이 똑같이 호가라서 매물끼리 비교하는 데는 문제가 없습니다.

## 1. 카테고리별 가중치 (100점 만점 기준)

| 카테고리 | 임대료 적정성 가중치 |
|---|---|
| 식당 | 15% |
| 카페 | 15% |
| 술집 | 15% |
| 소매 | 15% |
| 오피스 | 15% |
| 전시 | 15% |

- **6개 모두 같은 이유:** 임대료는 어떤 업종이든 가장 큰 고정비라서, 특별히 덜 중요한 업종이 없습니다.
- **다른 기준(10% 이하)보다 큰 이유:** 역세권, 유동인구, 점포 유지율은 동네를 간접적으로 보는 보조 지표지만, 임대료는 매물의 실제 가격이라 가장 직접적이고 확실한 데이터입니다.
- **20%가 아닌 이유:** 비중이 너무 크면 "싼 이유가 있는 매물"(낡음, 위치 불리 등)이 위로 올라오기 쉬워서 15%로 둡니다.

## 2. ㎡당 월세 계산

```
㎡당 월세 = 월세 ÷ 전용면적
```

예: 월세 200만원, 전용면적 75㎡ → ㎡당 2.67만원

- **보증금은 넣지 않습니다.** 보증금을 월세로 바꿔 더해 봐도(연 6%, 12% 모두 시험) 매물 순위가 거의 같았습니다 (순위 상관 0.997). 대구 공실 매물은 대부분 보증금이 월세에 비례해서 정해져 있어서, 월세만 봐도 충분합니다.
- **관리비는 넣지 않습니다.** 매물의 61%가 관리비 칸이 비어 있어서, 넣으면 관리비를 적은 매물만 손해를 봅니다.

## 3. 비교할 매물 고르기

아래 **세 가지가 같은** 다른 공실 매물과 비교합니다.

### ① 같은 층 (11단계)

| 층 그룹 | 포함되는 층 | 매물 수 |
|---|---|---|
| 지하 | 지하 1층, 지하 2층, 지하 3층 | 67 |
| 1층 | 1층 | 1,438 |
| 2층 | 2층 | 488 |
| 3층 | 3층 | 273 |
| 4층 | 4층 | 138 |
| 5층 | 5층 | 95 |
| 6층 | 6층 | 42 |
| 7층 | 7층 | 29 |
| 8층 | 8층 | 21 |
| 9층 | 9층 | 11 |
| 10층 이상 | 10층 ~ 19층 | 37 |

- **지하를 하나로 묶은 이유:** 지하 2층·3층 매물이 4곳뿐이라 따로 두면 비교할 수 없습니다.
- **10층 이상을 묶은 이유:** 10~19층은 층마다 1~11곳뿐이고, 모두 고층 업무 빌딩이라 성격이 비슷합니다.
- **층을 자세히 나눈 이유:** 처음에 "3층 이상"을 하나로 묶었더니 3층은 싸 보이고(0.87) 10층 이상은 비싸 보였습니다(1.18). 나눈 뒤에는 층별로 고르게 나옵니다 (5번 참고).

### ② 비슷한 크기 (3단계)

| 크기 | 전용면적 |
|---|---|
| 소형 | 50㎡ 미만 |
| 중형 | 50㎡ 이상 ~ 150㎡ 미만 |
| 대형 | 150㎡ 이상 |

- **크기를 나눈 이유:** 작은 매물은 원래 ㎡당 값이 비쌉니다. 크기를 나누지 않으면 33㎡ 미만 매물이 주변보다 평균 38% 비싸게 나와서 억울하게 감점됩니다.

### ③ 가까운 매물 (비교 매물이 5곳 이상 될 때까지 넓힘)

```
500m → 1km → 2km → 같은 구 → (그래도 5곳 미만이면) 판단 보류
```

- **대구 전체까지 넓히지 않는 이유:** 달성군 매물을 동성로 매물과 비교하는 식이 되어 믿기 어렵습니다.
- 비교 매물은 **나 자신을 뺀** 다른 매물입니다.

## 4. 비율과 점수

```
비율 = 이 매물의 ㎡당 월세 ÷ 비교 매물들의 ㎡당 월세 중간값
```

| 비율 | 뜻 | 점수 |
|---|---|---|
| 0.7 미만 | 주변보다 30% 이상 쌈 | **100** |
| 0.7 ~ 0.85 | 15~30% 쌈 | **85** |
| 0.85 ~ 0.95 | 5~15% 쌈 | **70** |
| 0.95 ~ 1.05 | 주변과 비슷 | **50** |
| 1.05 ~ 1.2 | 5~20% 비쌈 | **35** |
| 1.2 ~ 1.5 | 20~50% 비쌈 | **15** |
| 1.5 이상 | 50% 이상 비쌈 | **0** |

- **0.7 미만을 최고점으로 둔 이유:** "주변보다 30% 이상 싸다"는 이용자에게 이미 충분히 큰 차이입니다. 그보다 더 싼 매물에는 연세 계약, 아주 큰 평수, 불리한 위치처럼 **싼 이유가 있는 매물**이 섞여 있어서, 더 싸다고 점수를 계속 올리지 않습니다.
- **1.5 이상을 최저점으로 둔 이유:** 비율은 곱하기로 움직이기 때문에, 주변의 3분의 2(0.67)와 주변의 2분의 3(1.5)이 1.0에서 같은 거리입니다. 그래서 "30% 쌈(0.7)"과 "50% 비쌈(1.5)"이 대칭입니다. 실제로 0.7 미만(24%)과 1.5 이상(19%)의 매물 비율도 비슷합니다.
- **비싼 동네라고 감점되지 않습니다:** 같은 동네의 비슷한 매물끼리 비교하므로, 동성로처럼 원래 비싼 곳도 그 안에서 싸면 높은 점수를 받습니다. 위치 장점은 역세권·유동인구 점수에서 따로 반영됩니다.

## 5. 따로 처리하는 매물과 화면 표시

| 경우 | 점수 | 화면 표시 (필수) |
|---|---|---|
| **판단 보류**: 같은 구까지 넓혀도 같은 층·같은 크기 매물이 5곳 미만 | **50점** | "비교할 비슷한 매물이 부족해서 임대료 점수를 중간(50점)으로 표시했어요" |
| **9층 매물** (11곳): 매물이 적어 비교할 수 없음 | **50점** (판단 보류와 같음) | 판단 보류와 같은 문구 |
| **층 정보 없음** ("전체층", "기타" 26곳), **전용면적 10㎡ 미만** (4곳) | **50점** (판단 보류와 같음) | 판단 보류와 같은 문구 |
| **가격 극단값**: ㎡당 월세가 같은 층 그룹에서 상·하위 1% (48곳) | **50점** | "가격 정보 확인이 필요해요" |
| **매우 저렴**: 비율 0.5 미만 (극단값 제외) | 정상 계산 (100점) | "주변보다 매우 저렴해요 · 계약 조건(연세, 관리비 등)을 확인하세요" |

- **50점을 주는 이유:** 싼지 비싼지 판단할 근거가 없으므로, 이득도 손해도 없는 중간 점수를 줍니다. 최종 반영은 50 × 15% = 7.5점입니다.
- **가격 극단값 처리:** ㎡당 월세가 같은 층 그룹(지하 / 1층 / 2층 / 3층 이상)에서 상·하위 1%에 드는 매물(48곳)은 대부분 입력 실수이거나 조건이 특이한 매물입니다. 그래서 두 가지로 처리합니다.
  1. **다른 매물의 비교 기준에서 뺍니다.** 넣으면 주변 매물의 "보통 가격"이 흔들립니다.
  2. **자기 점수는 50점(판단 보류와 같음)**을 주고 "가격 정보 확인이 필요해요"를 표시합니다. 정상 계산하면 입력 실수인 매물이 100점이나 0점이 되기 때문입니다.

  | 극단값 예시 | ㎡당 월세 | 짐작되는 이유 |
  |---|---|---|
  | 이곡동 1층 115.7㎡, 월세 6,000만원 | 51.86만원 (1층 보통 1.64만원의 약 32배) | 600만원을 잘못 적은 것으로 보임 |
  | 감삼동 "1층" 202.66㎡, 월세 65만원 | 0.32만원 | 매물 설명에는 "건물 3층"이라고 적혀 있음 (층 입력 실수) |
  | 상인동 1층 143.63㎡, 월세 50만원 | 0.35만원 | "월세 연납" 조건이라 월세가 낮게 적힘 |

## 9. 참고 사항

- **비싸 보이는 매물 중 일부는 적는 방식 차이입니다.** "월세에 관리비·부가세 포함"으로 적은 매물(예: 동산동 "관리비 포함 500만원")은 실제보다 비싸게 계산됩니다. 매물 설명을 읽어 걸러내는 작업은 아직 하지 않았습니다.
- **경계값(0.7, 0.85, 0.95 등)은 판단으로 정한 값입니다.** 점수를 더 고르게 퍼뜨리고 싶으면, 점포 유지율처럼 "같은 조건 매물 중 몇 등인지"로 바꾸는 방법도 있습니다.
- **새 매물 데이터를 받으면** 비교 기준(중간값)이 바뀌므로 다시 계산합니다.
