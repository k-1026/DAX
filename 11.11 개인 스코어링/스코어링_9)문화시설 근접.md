### 중복 합치기

같은 시설이 여러 파일에 들어 있어서 하나로 합칩니다 (합친 기록 45건).

| 조건 | 합치나 |
|---|---|
| 이름이 똑같고 1km 안 | 합침 (자료마다 좌표가 수백 m 다르게 찍힌 경우가 있어서) |
| 이름이 비슷하고 150m 안 (예: 계명대 극재미술관 = 극재미술관, 대구 코오롱 야외음악당 = 코오롱 야외음악당) | 합침 |
| 이름이 다르면 가까워도 | 합치지 않음 (예: 대구간송미술관 ↔ 대구미술관, 신미화랑 ↔ 중앙갤러리, 같은 건물의 다른 소극장) |
| "박물관"과 "미술관"처럼 종류가 다르면 | 합치지 않음 (예: 경북대학교 박물관 ↔ 경북대학교 미술관) |

- 이름을 비교할 때 띄어쓰기, 괄호, "대구", "국립", "시립" 같은 말은 빼고 봅니다.
- 2배 시설과 1배 시설이 합쳐지면 2배로 남깁니다.

## 3. 점수 계산

### ① 문화시설 값

매물 주변 1km 안의 시설마다 **시설 배수 × 거리 배수**를 더합니다.

```
문화시설 값 = Σ (시설 배수 × 거리 배수)
```

| 거리 배수 | 매물과 시설의 거리 |
|---|---|
| × 1 | 500m 안 |
| × 0.5 | 500m ~ 1km |
| (세지 않음) | 1km 밖 |

- 가까운 시설일수록 손님이 오가기 쉬워서 500m 안은 그대로, 500m~1km는 절반으로 셉니다.

### ② 점수: 공실 매물끼리 줄 세우기

```
문화시설 근접 점수 = 공실 매물 중 "나보다 문화시설 값이 작거나 같은 매물" 수 ÷ 전체 매물 수 × 100
최종 반영 점수     = 문화시설 근접 점수 × 카테고리별 가중치
```

- **1km 안에 문화시설이 하나도 없으면(값 0) 20점**을 줍니다. 공실 매물의 31.5%가 여기에 해당합니다.
- **기준 목록:** 지금 공실 매물 2,669곳의 문화시설 값을 기준 목록으로 저장해 두고, 새 매물은 이 목록 안에서 몇 등인지 찾아 점수를 계산합니다. 그래서 새 매물이 들어와도 다른 매물의 점수는 바뀌지 않습니다.
- 문화시설 값은 카테고리와 상관없이 같으므로, 전시와 카페가 같은 기준 목록을 씁니다.

## 4. 참고 사항

- **문을 닫은 공연장이 섞여 있을 수 있습니다.** KOPIS 공연장 대부분은 운영 상태 칸이 비어 있어서, 폐업한 소극장이 있어도 데이터로는 알 수 없습니다.
- **작은 사설 화랑은 일부만 들어 있습니다.** 정식 등록된 미술관과 TourAPI의 화랑 몇 곳만 있어서, 봉산문화거리의 작은 화랑들은 대부분 빠져 있습니다.
- **문화시설이 중구에 몰려 있습니다.** 동성로·봉산문화거리 일대 매물은 높은 점수를 받고, 외곽 매물은 대부분 20점입니다.
- **새 데이터를 받으면** 시설 목록과 기준 목록을 다시 만듭니다.
