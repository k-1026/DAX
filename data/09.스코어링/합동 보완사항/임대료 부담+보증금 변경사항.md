# 임대료 부담+보증금 변경사항

작성일: 2026-11-17
기존 기준(`v2.대구 공실 스코어링 설계(11.16 버전).html`의 임대료 부담·보증금 인자)과 새 기준이 달라진 내용만 모았다.
새 기준 자체의 설명은 `비용_임대료 부담+보증금.md`에 있다.

## 1. 무엇을 바꿨나

기존 설계에서는 "임대료 부담"과 "보증금"이 서로 다른 인자였다. 이 둘을 하나의 인자로 합치고 계산식과 점수 방식을 바꿨다.

| | 기존 | 변경 |
|---|---|---|
| 인자 수 | 2개 (임대료 부담, 보증금) | 1개 (임대료 부담+보증금) |
| 사용자 입력 | 예산 1칸 | 월세 상한 1칸 + 보증금 상한 1칸 |
| 필터 | 월세 + 관리비 ≤ 예산 | 월세 ≤ 월세 상한 그리고 보증금 ≤ 보증금 상한 |
| 임대료 부담 식 | (월세 + 관리비) ÷ 예산 | 환산 월 임대료 = 월세 + 보증금 × 1% |
| 보증금 식 | 보증금 금액을 대구 분포 구간에 대입 | 위 환산 식에 1%로 환산해 포함 |
| 관리비 | 식에 포함 | 식에서 제외, 화면에 따로 표시 |
| 예산의 역할 | 필터 + 나누는 숫자 | 후보를 고르는 필터만 |
| 임대료 부담 점수 | 50% 이하 100점, 100%에서 40점 (모든 사용자에게 같은 구간) | 이용자 예산 안 후보를 환산 월 임대료가 싼 순서로 세워 10%씩 열 칸으로 나누고, 가장 싼 칸 100점부터 10점씩 깎아 가장 비싼 칸 10점 |
| 보증금 점수 | 500만 100점, 2,000만 60점, 8,000만 20점, 1억 이상 10점 | 별도 점수 없음 (통합 점수 하나로 계산) |
| 구간 사이 | 선형 보간 | 계단식 (같은 칸 안은 같은 점수) |
| 구간을 만드는 시점 | 미리 고정 | 이용자가 예산을 입력할 때마다 계산 |

## 2. 바꾼 이유

- 기존 임대료 부담 식은 월세와 관리비만 보고 보증금을 보지 않았다.
- 기존 보증금 점수는 사용자의 자금 사정과 무관하게 누구에게나 같았다.
- 기존 식과 구간(50% 이하 100점, 100%에서 40점)에는 인용할 근거가 없었다.
- 관리비는 결측이 1,657건(61%)이라 식에 넣으면 빈값을 0으로 채워야 했다.
- 기존 구간은 고정이라 예산이 크면 대부분 만점이 됐다. 월세 500만 / 보증금 1억 원 예산이면 기존 임대료 부담이 100점인 매물이 86.6%였다.
- 모든 이용자에게 같은 구간을 쓰려면 기준이 될 예산 하나를 정해야 하는데, 이용자마다 예산이 달라 그 기준을 정당화하기 어려웠다.

## 3. 기존에서 이어받은 것

- 구간을 매물 분포의 분위수로 잡는 방식은 기존 보증금 인자와 같다. 기존 보증금 인자는 대구 매물 전체의 분위수를, 새 기준은 이용자 예산 안 후보의 분위수를 쓴다.
- 점수 범위(가장 낮은 점수 10점, 가장 높은 점수 100점)는 기존 보증금 인자와 같다.

## 4. 기존에 있었는데 새 기준에서 자리가 없어진 것

- **무권리 +10점 가점**: 기존 보증금 인자에는 특징 칸에 "무권리"가 명시된 매물에 +10점을 주는 규칙이 있었다. 무권리는 권리금에 관한 정보라 새 통합 식에는 들어갈 자리가 없어 이 가점은 뺐다.
- **예산 미입력 시 처리**: 기존에는 예산을 입력하지 않으면 임대료 부담 인자를 빼고 보증금 점수만 계산했다. 새 기준에서는 대구 매물 전체를 후보로 두고 같은 방식으로 점수를 매긴다.

## 5. 함께 고쳐야 하는 곳

- 사용자 입력 칸이 1칸에서 2칸이 된다. 화면과 입력 설명을 맞춰야 한다.
- 기존 임대료 상한은 "월세 + 관리비"의 상한이었고, 새 월세 상한은 "월세"만의 상한이다. 입력 칸의 문구를 바꿔야 한다.
- 인자가 2개에서 1개가 되므로 인자 수를 적은 문서와 점수 설정을 고쳐야 한다.
- 점수 구간이 고정값이 아니라 이용자 입력마다 계산되므로, 점수 엔진이 예산을 받을 때마다 후보를 고르고 칸을 다시 나누도록 바꿔야 한다.
