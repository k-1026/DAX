# 입지 스코어링 모델 · 가중치 모델 조사

- 작성일: 2026-11-18
- 목적: 입지 그룹(교통 · 상권 활성도 · 배후 수요)의 점수식과, 업종별 그룹 안 비중을 하나의 기준으로 정할 수 있는 가중치 방법의 근거를 찾는다.
- 범위: 설문 없이 쓸 수 있는 방법을 우선한다. 업종별 그룹 가중치(탭 10 공통)는 다루지 않는다.
- 확인 수준: 모든 출처는 웹 검색 결과(초록, 서지, 공식 페이지, 2차 해설)로 확인했다. **논문 원문 본문은 읽지 않았다.** 2차 자료는 표에 표시했다.

## 2. 가중치 모델 10개: 원리를 그대로 적용할 수 있는가

### 평가 기준

우리가 필요한 것은 "업종별 그룹 안 비중의 차이를 하나의 기준으로 만드는 방법"이다. 다섯 가지로 평가했다.

| 기준 | 뜻 |
|---|---|
| ① 업종 차이 | 같은 규칙을 적용했을 때 업종마다 다른 비중이 나오는가 |
| ② 같은 규칙 | 모든 업종·그룹에 같은 식을 쓸 수 있는가 |
| ③ 지금 데이터 | 설문 없이 우리 데이터(2,717건, 중개사 추천 라벨, 입지 인자 점수)로 바로 계산되는가 |
| ④ 위험 | 순환(라벨로 만든 인자를 같은 라벨로 평가)·편향·불안정 |
| ⑤ 근거 | 그 원리를 쓰는 문헌이 있는가 |

적합도: **상** = 원리를 그대로 적용할 수 있고 지금 데이터로 계산됨, **중** = 원리는 맞지만 조건이 붙음, **하** = 원리는 맞지만 데이터가 없거나 우리 구조와 충돌.

## 3. 정리

- **통일된 기준으로 쓸 수 있는 원리는 1·2·3번입니다.** 셋 다 "중개사가 그 업종을 추천한 매물이 그 인자에서 전체와 얼마나 다른가"라는 같은 질문에 답합니다.
  - 지금 층 점수(선택비)와 같은 계열이라, 모델 전체의 논리가 하나로 이어집니다.
  - 업종마다 다른 비중이 데이터에서 나오므로, 업종별 차이를 둔다는 지금 구조를 그대로 유지합니다.
- **입지 그룹은 순환 문제가 없어 가장 깔끔하게 적용됩니다.** 교통·활성도·배후 수요는 라벨과 별개인 외부 데이터입니다.
- **공간 그룹은 교차검증이 필요합니다.** 층 점수·기본 면적을 학습 표본으로 만들고, 비중은 검증 표본에서 구해야 합니다.
- **업종 적합 그룹에는 이 기준을 쓸 수 없습니다.** 용도 일치도가 라벨 자체이기 때문입니다.
- **5번(실제 영향 맞춤)은 마무리 단계로 붙입니다.** 1~3번으로 정한 비중이 실제 순위에서도 그만큼 영향을 주는지 확인하고 보정합니다.
- **판정:** 방법은 "있음"(원리를 쓰는 문헌 있음)이고, 값은 우리 데이터로 계산한 뒤 "데이터 근거"가 됩니다.
