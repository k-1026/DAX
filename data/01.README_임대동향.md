# 상업용부동산 임대동향조사 데이터 (대구·서울·전국)

- 출처: 한국부동산원 R-ONE 부동산통계정보시스템 > 상업용부동산 임대동향조사 (https://www.reb.or.kr/r-one/portal/main/indexPage.do)
- 수집일: 2026-10-27 / 기간: 2019Q1 ~ 2026Q2 (조사일 기준 R-ONE 최신 공표 분기)
- 파일
  - `공실률_분기별.csv` 단위 %
  - `임대료_분기별.csv` 단위 R-ONE 표기 기준 천원/㎡ 추정 (사용 전 R-ONE 표에서 단위 확인)
  - `투자수익률_분기별.csv` 단위 % (분기 수익률, 소득수익률+자본수익률)
- 상가유형: 중대형 / 소규모 / 집합
- 구분: 전체(전국·서울·대구) / 권역(서울 도심·강남·영등포신촌·기타) / 상권(대구 상권별)

## 주의사항 (반드시 확인)

1. **2024년 3분기 시계열 단절**: 2024Q3부터 R-ONE이 별도 통계표(2024년3분기~)로 분리했고, 값이 크게 달라지는 구간이 있다. 예: 전국 중대형 공실률 2024Q2 13.8 → 2024Q3 12.7, 대구 18.2 → 15.5. 표본·방법 개편 가능성이 있어, 2024Q2와 2024Q3를 직접 이어 추세로 해석하지 말 것. (개편 사유는 R-ONE 통계 메타 확인 필요)
2. **상권 구분 변경**: 상권 구성이 시기별로 바뀌었다. 예) 동성로(2019) → 동성로중심·동성로외곽(2020~) → 동성로중심(2021~), 상인월배 → 상인/월배, 죽전 → 죽전역(2024Q3~). 상권명이 다르면 별도 행이며 서로 이어지지 않는다.
3. **집합상가 공실률**: R-ONE에 2022Q4부터만 있다. (임대료·수익률은 2019년부터 있음)
4. **서울 상권별 상세**: 파일에는 서울 전체와 4개 권역만 담았다. 서울 상권 단위(명동·홍대 등)는 R-ONE 해당 통계표에서 추가 수집 가능.
5. 2024Q3 이전 투자수익률 등 일부 상권 값은 표본이 작아 변동이 크다.
6. 수익률은 `투자수익률 = 소득수익률 + 자본수익률`을 확인했다. 소득·자본 수익률은 필요 시 추가 수집 가능.
