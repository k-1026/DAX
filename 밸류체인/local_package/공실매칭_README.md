# 공실매칭

## 팀 자산
**대구 공실 매물 데이터**: 대구 지역 상가·사무실 등 비어 있는 매물 정보

## 핵심 메시지
> 대구에서 공실을 찾는 지역민에게, 자체 스코어링 기준으로 **업종별 맞춤 매물**을 추천한다.

| 요소 | 내용 |
|---|---|
| 대상(Who) | 대구에서 공실을 찾는 지역민(예비 창업자, 이전·확장하려는 자영업자) |
| 자산(What) | 대구 공실 매물 데이터 |
| 차별점(How) | 자체 스코어링 기준으로 업종에 맞춰 매물 적합도를 평가 |
| 결과(Value) | 업종별 맞춤 매물 추천 |

## 트랙 산업
부동산 · 추천 서비스
