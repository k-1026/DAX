# 대구 빈 상가 찾기 · 서브에이전트 구성

상담 에이전트 1개가 사용자와 대화하고, 그 아래 서브에이전트 5개가 일을 나눠 맡는다. 같은 내용의 화면용 파일은 `서브에이전트 구성도.html`이고, 에이전트별 자세한 명세는 `00_상담에이전트.md`~`07_상담준비.md`에 있다.

## 구조

```
사용자 (가게 자리를 찾는 예비 창업자)
        │

        │
 ┌──────┼──────────┬──────────┬──────────┐
 ①      ②          ③          ④          ⑤
조건   매물 수집   입지·상권   점수·추천   설명·보고
파악   ·검증       분석
```

## 한 번의 상담 흐름

1. **묻기**: "수성구에 월 200 안쪽으로 학원 자리 있을까요?" → ①이 업종·월세·지역을 뽑는다.
2. **고르기**: ④가 미리 준비된 매물(②)과 주변 정보(③)로 순위를 매긴다.
3. **설명하기**: ⑤가 상위 상가의 좋은 점과 확인할 점을 쉬운 말로 풀어 준다.
4. **다시 묻기**: "더 싼 곳은요?" → 상담 에이전트가 ④와 ⑤만 다시 부른다. ②③은 다시 돌리지 않는다.

## 설계할 때 지킬 세 가지

1. **점수는 AI가 아니라 코드로.** 같은 조건에는 항상 같은 점수가 나와야 하고, 왜 그 점수인지 설명할 수 있어야 한다. AI는 말 알아듣기(①)와 쉬운 말로 풀기(⑤)에만 쓴다.
2. **설명은 받은 숫자만으로.** ⑤는 점수와 실제 값을 받아 문장으로 바꾸기만 한다. 데이터에 없는 내용은 말하지 않는다.
3. **확인이 필요한 건 사람에게.** 입점 가능 여부(구청 건축과)와 계약 여부(중개사)는 단정하지 않고 "확인할 점"으로 넘긴다.
