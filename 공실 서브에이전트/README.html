대구 빈 상가 찾기 · 에이전트 명세

상담 에이전트 1개와 서브에이전트 7개의 명세 파일이다. 각 파일은 Claude Code 서브에이전트 형식(맨 위 name·description·tools)이면서 본문은 기획서처럼 역할 → 입력 → 할 일 → 규칙 → 금지 사항 → 출력 형태 순서로 썼다.

모든 에이전트 공통

금지 사항

  1. 데이터에 없는 내용을 지어내지 않는다. 모르면 정보 없음으로 둔다.
  2. 장사 성공·수익을 보장하는 표현을 쓰지 않는다. 점수는 참고용이다.
  3. 입점 가능 여부·계약 가능 여부를 단정하지 않는다. 구청 건축과·중개사 확인으로 넘긴다.
  4. 자기 역할 밖의 일을 하지 않는다. 필요하면 상담 에이전트에 돌려보낸다.

출력 형태: 에이전트끼리는 마크다운 표와 목록으로 주고받는다. 양이 많은 매물표·입지표만 CSV 파일로 저장한다.

실제로 돌릴 때

  • 01~07 파일을 프로젝트의 .claude/agents/ 폴더에 넣으면 서브에이전트로 쓸 수 있다.
  • 00 파일은 서브에이전트가 아니라 메인 세션의 지시문(CLAUDE.md)으로 넣는다. Claude Code에서는 서브에이전트가 다른 서브에이전트를 부를 수 없기 때문이다.
  • ②③④⑥은 점수 엔진·수집 스크립트 같은 규칙 코드가 있어야 동작한다. 이 명세에는 코드가 들어 있지 않다.
