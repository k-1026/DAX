# 에이전트 실행 — 다음에 할 일 제안 규칙

> 이 파일의 문구와 기준 숫자를 고치면 관리자 화면 "에이전트 실행"의 제안이 바뀝니다(서비스에 반영하려면 배포가 필요해요).
> 이 화면은 몇 초마다 새로 읽기 때문에 제안도 같이 바뀝니다.
> 쓸 수 있는 이름: 실패_에이전트_수, 경고_에이전트_수, 기타_경고_에이전트_수(경고 중 다른 제안에서 이미 설명한 것을 뺀 수), 실행중_에이전트_수, 실행중_최장_분(지금 실행 중인 작업이 시작한 뒤 지난 분),
> 점검_이상_수, 점검_기록_없음(1/0), 점검_마지막_경과_분, 주간_기록_없음(1/0), 주간_경과_일(마지막 성공 후), 주간_경보_기준_일(설정값에서 읽어 옴),
> 갱신_기록_없음(1/0), 갱신_경과_시간(마지막 성공 후), 갱신_경보_기준_시간(설정값에서 읽어 옴), 메일_기록_없음(1/0), 기록_없는_에이전트_수

## 기준 숫자
- 실행_오래됨_분: 30
- 점검_멈춤_분: 15
- 기록없음_안내_기준: 2

## 상황: 실패한 에이전트가 있어요
- 수준: 지금 확인
- 조건: 실패_에이전트_수 >= 1
- 해석: 마지막 실행이 실패한 에이전트가 {실패_에이전트_수}개 있어요.
- 할 일: 빨간 불이 켜진 카드를 눌러 로그에서 실패한 단계와 이유를 확인해 주세요. 같은 실패가 반복되면 개발 담당에게 알려 주세요.

## 상황: 시스템 점검에서 이상이 발견됐어요
- 수준: 지금 확인
- 조건: 점검_이상_수 >= 1
- 해석: 최근 점검에서 이상이 있는 항목이 {점검_이상_수}곳이에요.
- 할 일: '시스템 점검' 카드의 로그에서 어느 항목(사이트·DB·갱신 누락·메일 실패 등)인지 확인하고 원인을 찾아 주세요.

## 상황: 실행 중인 작업이 너무 오래 걸려요
- 수준: 지금 확인
- 조건: 실행중_최장_분 >= 실행_오래됨_분
- 해석: 지금 실행 중인 작업이 시작한 지 {실행중_최장_분}분이 지났어요.
- 할 일: 멈춘 것은 아닌지 로그의 마지막 줄 시각을 확인해 주세요. 한 시간 넘게 변화가 없으면 개발 담당에게 알려 주세요.

## 상황: 시스템 점검이 멈춘 것 같아요
- 수준: 곧 점검
- 조건: 점검_기록_없음 == 0 그리고 점검_마지막_경과_분 >= 점검_멈춤_분
- 해석: 마지막 점검 기록이 {점검_마지막_경과_분}분 전이에요(5분마다 도는 작업이에요).
- 할 일: 점검 호출이 계속 오고 있는지, 서버 예약 설정이 켜져 있는지 확인해 주세요.

## 상황: 매물 갱신이 기준 시간을 넘겼어요
- 수준: 곧 점검
- 조건: 갱신_기록_없음 == 0 그리고 갱신_경과_시간 >= 갱신_경보_기준_시간
- 해석: 마지막 성공 후 {갱신_경과_시간}시간이 지났어요(기준 {갱신_경보_기준_시간}시간).
- 할 일: '매물 갱신' 화면에서 이유를 확인하고, 수집 담당에게 새 데이터 전달 여부를 물어봐 주세요.

## 상황: 주간 분석이 기준 일수를 넘겼어요
- 수준: 곧 점검
- 조건: 주간_기록_없음 == 0 그리고 주간_경과_일 >= 주간_경보_기준_일
- 해석: 주간 분석이 마지막 성공 후 {주간_경과_일}일 동안 성공하지 못했어요(기준 {주간_경보_기준_일}일).
- 할 일: 주간 분석 카드의 로그에서 실패 이유를 확인하고, 매주 월요일 실행이 예약되어 있는지 점검해 주세요.

## 상황: 경고 상태인 에이전트가 있어요
- 수준: 곧 점검
- 조건: 기타_경고_에이전트_수 >= 1
- 해석: 위에서 설명하지 않은 노란 불 에이전트가 {기타_경고_에이전트_수}개 있어요.
- 할 일: 카드의 한 줄 설명을 읽고 해당 화면(매물 갱신·메일 발송)에서 자세한 이유를 확인해 주세요.

## 상황: 예약 실행이 아직 등록되지 않았을 수 있어요
- 수준: 참고
- 조건: 기록_없는_에이전트_수 >= 기록없음_안내_기준
- 해석: 실행 기록이 하나도 없는 에이전트가 {기록_없는_에이전트_수}개예요.
- 할 일: 서비스를 올릴 때(9단계) 서버에 예약 실행을 등록해야 해요. 그 전에는 직접 호출할 때만 기록이 생겨요.

## 기본: 에이전트가 모두 정상이에요
- 해석: 실패한 에이전트와 점검 이상이 없고, 실행 중인 작업도 오래 걸리지 않아요.
- 할 일: 그대로 지켜보세요. 이상이 생기면 카드의 불빛이 바뀌어요.
