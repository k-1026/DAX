# 비용: 임대료 부담+보증금

작성일: 2026-11-17
상태: 계산식·점수 방식 확정

## 1. 계산식

```
입력:  월세 상한 A,  보증금 상한 B

1. 후보 고르기:  월세 ≤ A  그리고  보증금 ≤ B 인 대구 매물       (둘 다 만족해야 목록에 표시)
2. 환산하기:     환산 월 임대료 = 월세 + 보증금 × 1%
3. 줄 세우기:    후보를 환산 월 임대료가 싼 순서로 세운다
4. 경계값 구하기: 후보의 환산 월 임대료 10%, 20%, … 90% 분위값을 구한다
5. 점수:         10% 경계값 이하 100점, 20% 경계값 90점, … 90% 경계값 20점, 가장 비싼 후보 10점
                 경계값 사이는 선형 보간한다
```

- 단위는 만원이다.
- 이용자가 적은 A와 B는 후보를 고르는 데만 쓴다. 점수는 후보끼리의 순서로 정해진다.
- 관리비는 식에 넣지 않는다. 화면에는 따로 표시한다.
- 필터는 칸마다 따로 적용한다. 월세와 보증금을 환산해 합치는 것은 줄을 세울 때뿐이다.

필터를 칸마다 따로 두는 이유: 환산 예산 하나로만 거르면 보증금을 낼 수 없는 매물이 통과한다. 월 100만 / 보증금 1,000만 원 예산으로 시험했을 때, 환산 예산만으로 거르면 보증금 상한을 넘는 매물 229건이 통과했다.

## 2. 계산식의 근거

| 식의 부분 | 근거 자료 | 내용 |
|---|---|---|
| 월세 + 보증금 × 전환율 ÷ 12 | 한국부동산원 상업용부동산 임대동향조사 (국가승인통계 제408001호) 통계산출항목 | 환산임대료 = (보증금 × 전환율 ÷ 12) + 월 임대료 |
| 전환율 연 12% | 상가건물 임대차보호법 시행령 제5조 | 보증금을 월 차임으로 전환할 때의 상한: 연 1할2푼과 한국은행 기준금리 × 4.5배 중 낮은 값 |
| 보증금 × 1% | 상가건물 임대차보호법 시행령 제2조 제3항 | 환산보증금 = 보증금 + 월세 × 100. 월 1%(연 12%)와 같은 비율 |
| 관리비 제외 | 한국부동산원 통계산출항목 | 환산임대료는 관리비 등의 수입을 포함하지 않고 부가가치세도 제외 |

연 12% ÷ 12개월 = 월 1%이므로 식에서 `보증금 × 1%`로 적는다.

출처 링크

- 한국부동산원 상업용부동산 임대동향조사 (통계산출항목 포함): https://www.reb.or.kr/reb/cm/cntnts/cntntsView.do?mi=10335&cntntsId=1049&statId=S237220284
- 상가건물 임대차보호법 시행령 제2조: https://www.law.go.kr/법령/상가건물임대차보호법시행령/제2조
- 상가건물 임대차보호법 시행령 제5조: https://www.law.go.kr/법령/상가건물임대차보호법시행령/제5조

근거가 없는 부분 (우리 설계)

- 12%는 법정 상한이지 시장의 실제 전환율이 아니다. 한국부동산원이 상권별 전환율을 공표하지만 대구 수치는 확인하지 못했다.
- 후보의 10% 경계값마다 100점부터 10점씩 내려가는 점수를 찍고 그 사이를 선형 보간하는 방식은 우리 설계다.

## 3. 점수가 나오는 방식

후보를 환산 월 임대료가 싼 순서로 세운 뒤, 10%마다 경계값을 구해 아래 점수를 찍는다. 경계값 사이는 선형 보간한다.

| 위치 | 점수 |
|---|---|
| 10% 경계값 이하 | 100 |
| 20% 경계값 | 90 |
| 30% 경계값 | 80 |
| 40% 경계값 | 70 |
| 50% 경계값 (중앙값) | 60 |
| 60% 경계값 | 50 |
| 70% 경계값 | 40 |
| 80% 경계값 | 30 |
| 90% 경계값 | 20 |
| 가장 비싼 후보 | 10 |

### 3-1. 경계값

- 경계값은 후보들의 환산 월 임대료 10%, 20%, … 90% 분위값이다.
- 경계값은 줄의 자리가 아니라 금액이다. 점수도 줄에서 몇 번째인지가 아니라 환산 월 임대료가 얼마인지로 정해진다.

### 3-2. 같은 가격은 같은 점수

- 점수를 금액으로 계산하므로 같은 가격의 매물은 반드시 같은 점수를 받는다.

### 3-3. 선형 보간

- 경계값 사이에서는 가격이 비싼 만큼 점수가 조금씩 내려간다.
- 예를 들어 85만 원이 50% 경계값(60점)이고 100만 원이 60% 경계값(50점)이면, 그 사이 15만 원 동안 점수가 10점 내려가므로 86만 원은 약 59.3점이다.
- 경계를 넘어도 점수가 한 번에 크게 바뀌지 않는다.

## 4. 이 방식의 성질

- 이용자마다 자기 예산 안의 후보로 줄을 세우므로, 다른 사람의 예산이나 기준 예산을 쓰지 않는다.
- 예산이 얼마든 100점을 받는 매물(10% 경계값 이하)은 후보의 약 10%다. 다만 싼 쪽에 같은 가격이 몰리면 10%보다 많아질 수 있다(예: 월세 30만 / 보증금 300만 원이면 16.1%, 5장 참고).
- 같은 예산이면 같은 매물은 항상 같은 점수다. 이를 위해 후보는 A와 B로만 고르고, 지역·면적 필터나 정렬은 줄 세우기에 반영하지 않는다.
- 줄 세우기와 경계값 구하기는 이용자가 예산을 입력할 때마다 다시 계산한다.
- 점수의 뜻: "내가 빌릴 수 있는 가게 중 얼마나 싼 편인가."

## 5. 입력 상태별 처리

| 입력 상태 | 후보 | 점수 |
|---|---|---|
| A, B 둘 다 입력 | 월세 ≤ A 그리고 보증금 ≤ B | 3번 방식 |
| 월세 상한만 입력 | 월세 ≤ A | 3번 방식 |
| 보증금 상한만 입력 | 보증금 ≤ B | 3번 방식 |
| 둘 다 미입력 | 대구 매물 전체 | 3번 방식 |

후보가 적을 때

- 후보가 몇 건이든 같은 계산식과 같은 점수 방식을 쓴다. 최소 후보 수는 두지 않는다.
- 후보가 적거나 같은 가격이 몰려 있으면 경계값이 겹쳐 매물이 고르게 나뉘지 않는다. 예를 들어 월세 30만 / 보증금 300만 원이면 후보가 56건인데, 가장 비싼 가격(환산 33만 원)에 24건이 몰려 있어 60~90% 경계값이 모두 33만 원이 된다. 이 24건은 60% 경계값 점수인 50점을 받고, 10점을 받는 매물은 없다. 100점은 9건(16.1%)이다.
- 후보가 1건이면 그 매물은 100점이다. 후보가 2건이면 싼 쪽 100점, 비싼 쪽 10점이고, 3건이면 100점, 60점, 10점이다.

## 6. 한계

- 예산이 넉넉해도 점수가 10~100점으로 고르게 퍼진다. 돈 걱정이 적은 이용자에게도 싼 가게가 계속 위로 올라온다.
- 한국은행 기준금리 × 4.5배가 12%보다 낮아지면(기준금리 2.67% 미만) 법정 상한이 달라진다. 2026-11-16 기준금리 3.00%에서는 12%가 상한이다.
- 경계값마다 10점씩 내려가는 점수 방식은 사용자 good/bad 피드백으로 검증되기 전까지는 가설이다.

## 7. 재현 방법

```python
import csv

rows = list(csv.DictReader(open('07.대구_매물유형별_csv/대구_구역별_매물 (최종).csv', encoding='utf-8-sig')))
data = [(r['매물번호'], float(r['월세']), float(r['보증금'])) for r in rows]

def quantile(a, p):                    # 선형 보간 분위수
    i = (len(a) - 1) * p / 100
    lo = int(i); hi = min(lo + 1, len(a) - 1)
    return a[lo] + (a[hi] - a[lo]) * (i - lo)

def make_scorer(A=None, B=None):
    # 1. 후보 고르기 (입력한 칸만 적용)
    pool = [(i, m + d * 0.01) for i, m, d in data
            if (A is None or m <= A) and (B is None or d <= B)]
    # 2~4. 환산 월 임대료로 줄 세우고 10% 경계값 구하기
    costs = sorted(c for _, c in pool)
    cuts = [quantile(costs, p) for p in range(10, 100, 10)]
    # 5. 눈금: 10% 경계값 100점, 20% 경계값 90점 … 90% 경계값 20점, 가장 비싼 후보 10점
    marks = [(x, 100 - 10 * k) for k, x in enumerate(cuts)] + [(costs[-1], 10)]

    def score(c):                      # 눈금 사이는 선형 보간
        if c <= marks[0][0]:
            return 100.0
        for (x0, y0), (x1, y1) in zip(marks, marks[1:]):
            if c <= x1:
                return y0 if x1 == x0 else y0 + (y1 - y0) * (c - x0) / (x1 - x0)
        return 10.0

    return pool, score

pool, score = make_scorer(150, 2000)   # 예: 월세 150만, 보증금 2,000만
print(len(pool), [round(score(c), 1) for c in (44, 60, 85, 86, 140, 141)])
# 1499 [99.8, 85.0, 60.0, 59.3, 20.0, 19.7]
```
