# 디자인 레이아웃

- 작성일: 2026-11-26
- 원본: `업종 적합 그룹.html` (같은 폴더)
- 용도: 다른 그룹(비용, 공간, 입지 등) 화면을 만들 때 `업종 적합 그룹.html`과 같은 모양이 나오도록, 색·글꼴·화면 구성·부품·스크립트를 그대로 옮겨 둔 문서
- 쓰는 법: 6장의 **페이지 뼈대**를 복사하고, `<style>`에는 7장 CSS 전체를, `<script>`에는 8장 공통 스크립트를 넣는다. 그다음 4·5장의 부품을 골라 내용만 바꿔 채운다.

## 1. 화면 전체 구성

```
┌──────────────────────────────────────────────┐
│ 그룹 이름 (h1)            [개요] [인자1] [인자2] │  ← 위에 붙어 있는 머리줄 + 탭
├──────────────────────────────────────────────┤
│  h2 제목                                      │
│  설명 한 줄 (lead)                             │
│  (●계산 흐름) (●분류 방법) (●예시) …            │  ← 인자 탭에만: 목차 알약
│                                              │
│  [1] 계산 흐름 ──────────                      │  ← 번호 붙은 소제목
│  ┌ 카드 ┐ ┌ 카드 ┐   (2칸 / 3칸 / 4칸 격자)     │
│  [2] … ──────────                             │
│  ┌ 카드 ──────────────────┐                    │
├──────────────────────────────────────────────┤
│ 바닥글: 그룹 이름 · 출처 문서와 날짜              │
└──────────────────────────────────────────────┘
```

- 한 HTML 파일 안에 탭마다 `section.panel`이 하나씩 있다. 탭을 누르면 그 패널만 보인다.
- 가운데 폭은 최대 1080px, 양옆 여백 16px. 화면 폭이 760px 이하이면 격자(2·3·4칸)가 한 줄로 쌓인다.
- 밝은 화면과 어두운 화면을 모두 지원한다 (운영체제 설정을 따르고, `data-theme`으로 고정할 수도 있음).
- 외부 파일을 하나도 불러오지 않는다. 그림표도 모두 HTML 막대와 CSS로 그린다.

## 2. 탭과 각 탭의 내용 순서

### 2-1. 탭

| 탭 | 내용 |
|---|---|
| 개요 | 그룹이 무엇을 재는지, 인자별 요약 카드, 인자끼리 무엇이 다른지, 공통 정보, 출처 문서 표 |
| 인자 하나마다 탭 하나 | 그 인자의 계산식·근거 문서 3개(계산식, 변경사항, 근거자료)를 한 화면에 정리 |

- 탭 이름은 인자 이름 그대로 짧게 쓴다 (예: "용도 일치도", "건물 용도").
- 탭의 `data-tab` 값과 패널의 `id`를 같게 맞춘다 (예: `ov`, `use`, `bld`).

### 2-2. 개요 탭 순서

1. `h2` "그룹 이름: 한 줄 질문" (예: "업종 적합 그룹: 이 매물에 고른 업종이 맞는가")
2. `p.lead` 그룹 설명 2~3문장
3. `grid2`(인자가 3개면 `grid3`) 안에 **인자 요약 카드** 하나씩 (4-1 참고)
   - 맨 위 `pill`로 "인자 1", "인자 2"
   - `h3` 인자 이름
   - 굵은 한 줄 질문 ("중개사가 이 업종을 추천했는가")
   - 표: 보는 자료 / 점수 단계 / 빈칸 처리 / 대상 / 상태
4. 카드: 인자끼리 보는 것이 어떻게 다른지 (`hflow` 상자를 인자 색 왼쪽 띠로 구분) + `note` 공통 주의
5. 카드: 그룹 공통 정보 (예: 업종 8개를 `grid4` + `stat`으로)
6. 카드: "이 화면의 출처 (N개 문서)" 표 — 열은 인자 / 계산식 / 변경사항 / 근거자료

### 2-3. 인자 탭 순서

인자 문서 3개(`그룹_인자.md`, `인자 변경사항.md`, `인자 근거자료.md`)의 내용을 아래 순서로 배치한다. 필요 없는 칸은 빼고, 번호는 1부터 다시 매긴다.

| 번호 | 소제목 | 주로 쓰는 부품 | 가져오는 문서 |
|---|---|---|---|
| (머리) | `h2` 인자 이름 + `lead` "점수의 뜻: …" · 작성일 · 상태 | | 계산식 |
| (목차) | `nav.toc` 소제목으로 가는 알약 링크 | | |
| 1 | 계산 흐름 | `flow`(세로 단계), `dec`(판정 사다리) | 계산식 1장 |
| 2 | 분류·판정 방법 | `hflow`(가로 단계), 표 | 계산식 2장 |
| 3 | 예시 | 표 + `pill` | 계산식 3장 |
| 4 | 분포 | `bigstack`, `stat`+`big`, `bars` | 계산식 3장 |
| 5 | 기존에서 바뀐 점 | 기존/변경 비교 막대, `table.chg`, `ul.clean` | 변경사항 |
| 6 | 근거 | `bars`, `cols`, `warn`, "한 장 정리" 표 | 근거자료 |
| 7 | 한계 | `ul.clean` | 계산식 한계 |

- 소제목마다 `div.secttl`(번호 + `h3`)을 쓰고, `id`를 목차 링크와 맞춘다 (예: 용도 일치도는 `u1`~`u7`, 건물 용도는 `b1`~`b11`처럼 탭마다 앞글자를 다르게).
- 내용이 많은 인자는 소제목을 더 나눠도 된다 (건물 용도: 매칭 신뢰도, 층 줄 고르기, 등급, 업종별 규칙, 검증, 법령 근거 등 11개).
- 우리 설계(외부 근거 없음)인 부분은 표 안에서 `<span class="pill pX">우리 설계</span>`로 표시한다.
- 맨 아래 `footer`에 "그룹 이름 · 출처: 인자 3개 문서(날짜), …"를 적는다.

| `--hl` | #fff4d6 | #3a3220 | 경고·강조 상자 바탕 (`warn`), 그림표의 강조 구간 |

### 3-2. 색 쓰는 규칙

- **4등급 점수**(A·B·C·D)는 `gA`·`gB`·`gC`·`gD`, 제외는 `gX`.
- **3단계 점수**(명시·다용도·그 밖처럼 등급이 아닌 단계)는 `u1`·`u2`·`u3`.
- **판정 결과**(맞음·애매·틀림)는 `gA`·`gC`·`gD`, 판단 불가는 `gX`.
- **기존 → 변경** 비교는 기존 `gX`, 변경 `accent`.
- 인자 요약 카드의 "인자 1/2" 알약 색은 그 인자의 대표 색을 쓴다 (용도 일치도 `p1`, 건물 용도 `pB`).
- 새 그룹에서 색이 더 필요하면 `:root` 세 곳(밝은 화면, 어두운 화면 자동, 어두운 화면 고정)에 똑같이 추가한다.

## 5. 부품 모음

아래 HTML을 복사해 글자와 숫자만 바꿔 쓴다.

### 5-1. 카드와 격자

```html
<div class="grid2">            <!-- grid3, grid4도 같은 방식 -->
  <div class="card">
    <h3>카드 제목</h3>
    <p>본문</p>
    <p class="note">보조 설명</p>
  </div>
  <div class="card">…</div>
</div>
```

### 5-2. 번호 붙은 소제목과 목차

```html
<nav class="toc">
  <a href="#x1">계산 흐름</a><a href="#x2">분류 방법</a><a href="#x3">예시</a>
</nav>

<div class="secttl" id="x1"><span class="n">1</span><h3>계산 흐름</h3></div>
```

목차 링크를 누르면 머리줄 높이(70px)만큼 띄워서 부드럽게 이동한다 (8장 스크립트).

### 5-3. 인자 요약 카드 (개요 탭)

```html
<div class="card">
  <span class="pill p1">인자 1</span>
  <h3 style="margin-top:8px">인자 이름</h3>
  <p style="font-size:17px;font-weight:700;margin:0 0 10px">"이 인자가 묻는 한 줄 질문"</p>
  <table>
    <tr><th>보는 자료</th><td>…</td></tr>
    <tr><th>점수 단계</th><td><span class="pill p1">명시 100</span> <span class="pill p2">다용도 50</span> <span class="pill p3">그 밖 25</span></td></tr>
    <tr><th>빈칸</th><td>…</td></tr>
    <tr><th>대상</th><td>…</td></tr>
    <tr><th>상태</th><td>…</td></tr>
  </table>
</div>
```

### 5-4. 알약(pill)과 꼬리표(tag), 코드 글씨(kbd)

```html
<span class="pill pA">A 100</span> <span class="pill pB">B 80</span>
<span class="pill pC">C 40</span> <span class="pill pD">D 30</span> <span class="pill pX">우리 설계</span>
<span class="pill p1">명시</span> <span class="pill p2">다용도</span> <span class="pill p3">그 밖</span>
<span class="tag">특징 칸만</span>
<span class="kbd">classify_use.py</span>
```

### 5-5. 세로 단계 흐름 (flow)

```html
<div class="flow">
  <div class="fstep"><div class="no">1</div><div><b>단계 이름</b><span class="d">설명</span></div></div>
  <div class="farrow">↓</div>
  <div class="fstep"><div class="no">2</div><div><b>단계 이름</b><span class="d">설명</span></div></div>
</div>
```

### 5-6. 가로 단계 흐름 (hflow)

```html
<div class="hflow">
  <div class="box"><b>① 단계</b>설명<br><span class="note">예시</span></div>
  <div class="ar">→</div>
  <div class="box"><b>② 단계</b>설명</div>
</div>
```

- 화살표(`ar`)는 좁은 화면에서 숨는다.
- 화살표 없이 상자만 나란히 두고 `style="border-left:4px solid var(--u1)"`처럼 왼쪽 띠 색을 주면 "둘을 비교하는 상자"가 된다 (개요 탭).

### 5-7. 판정 사다리 (dec) — "위에서부터, 처음 맞는 조건에서 끝"

```html
<div class="dec">
  <div class="q">조건 1?</div>
  <div class="res" style="background:var(--u1)">결과 100<small>짧은 뜻</small></div>
  <div class="no">↓ 아니오</div>
  <div class="q">조건 2?</div>
  <div class="res" style="background:var(--u2)">결과 50<small>짧은 뜻</small></div>
  <div class="no">↓ 아니오</div>
  <div class="q">둘 다 아님</div>
  <div class="res" style="background:var(--u3);color:var(--ink)">결과 25<small>짧은 뜻</small></div>
</div>
```

`flow` 안에 넣어 단계 다음에 판정이 이어지게 할 수도 있다 (건물 용도 "단지 내 상가").

### 5-8. 숫자 상자 (stat + big)

```html
<div class="grid4">
  <div class="stat"><div class="k">항목 이름</div><div class="big">3,626</div><div class="note">단위</div></div>
  …
</div>
```

- 큰 숫자 대신 굵은 한 줄을 넣어도 된다: `<div style="font-weight:700">…</div>`.
- 카드 안에서 결과 숫자를 크게 보이려면 `<div class="big" style="color:var(--gA)">94.9%</div>` (검증 결과 카드).

### 5-9. 등급 카드 (gcard) — 색 바탕에 흰 글자

```html
<div class="grid4">
  <div class="gcard" style="background:var(--gA)"><div class="gl">A · 100</div><div class="gs">한 줄 뜻</div><p>보조 설명</p></div>
  …
</div>
```

### 5-10. 단계 사다리 (ladder) — 순서 있는 목록에서 우리 위치 강조

```html
<div class="ladder">
  <div class="rung"><span class="num">1</span><span>항목 <span class="ex">보조</span></span><span class="pill pC">C</span></div>
  <div class="rung me"><span class="num">7</span><span><b>강조할 항목</b></span><span class="pill pB">A / B</span></div>
</div>
```

`me`를 붙인 줄은 강조 테두리와 연한 강조 바탕이 된다.

### 5-11. 경고·판단 상자 (warn)

```html
<div class="warn"><b>판정: 부분 일치</b><br>설명<br><br><span class="note">보조 설명</span></div>
```

"팀 판단", "판정", 꼭 알아야 할 주의를 넣는 곳이다.

### 5-12. 표

```html
<div class="tbl"><table>
  <tr><th>항목</th><th class="r">숫자</th></tr>
  <tr><td>…</td><td class="r">1,234</td></tr>
</table></div>
```

- 넓은 표는 `div.tbl`로 감싸 좁은 화면에서 옆으로 밀리게 한다.
- 숫자 칸은 `class="r"` (오른쪽 정렬, 숫자 폭 고정).
- 바뀐 점 표는 `table.chg`: 2번째 열(기존)은 흐리게, 3번째 열(변경)은 굵게.
- 등급 격자 표는 `table.mx` + 칸 안에 `div.cell` / `div.ln` (5-15 스크립트로 생성).
- 표 안에서 바뀐 말을 강조할 때는 `<mark>` (예: 키워드 표의 "점핑").

### 5-13. 목록

```html
<ul class="clean"><li>…</li></ul>
<ul class="clean note"><li>작은 글씨 목록</li></ul>
```

### 5-14. 범례 (legend)

```html
<div class="legend"><span><i style="background:var(--gA)"></i>맞음</span><span><i style="background:var(--gD)"></i>틀림</span></div>
```

그림표 바로 위에 둔다.

### 5-15. 그림표 (모두 HTML·CSS로 그림)

| 부품 | 모양 | 쓰는 곳 | 만드는 법 |
|---|---|---|---|
| `bars` | 가로 막대 (이름 / 막대 / 값) | 건수·비율 비교 | 빈 `<div class="bars" id="…">` + 스크립트 `bars()` |
| `stack` | 가로로 나뉜 막대 (줄마다 합 100%) | 업종별 등급 분포, 판정 결과 | 빈 `<div id="…">` + `stacks()` |
| `bigstack` | 굵은 한 줄 비율 막대 | 전체 비율 한눈에 | HTML로 직접 (아래) |
| `cols` + `colx` | 세로 막대 + 아래 이름 줄 | 구간별 값 (예: 날짜 차이별 일치율) | 빈 `cols`·`colx` + 짧은 스크립트 |
| `wf` + `wfx` | 폭포 그림 (단계마다 줄어드는 수) | "2,531 → 2,452"처럼 단계별 변화 | 빈 `wf`·`wfx` + 짧은 스크립트 |
| 두 줄 막대 | 한 줄에 막대 두 개 (기존/변경 또는 지표 2개) | 기존 → 변경 비교, 두 점검 비교 | 짧은 스크립트로 `tr` 두 개 |

- 특정 구간을 강조하려면 그 칸 `div.c`에 `background:var(--hl)`을 준다 (건물 용도 "기존 허용 폭").

## 9. 새 그룹을 만들 때 순서

1. 그룹의 인자마다 3개 문서(계산식, 변경사항, 근거자료)가 있는지 확인한다.
2. 6장 뼈대를 복사해 `○○ 그룹.html`로 저장하고, 7장 CSS와 8장 스크립트를 붙인다.
3. 탭을 인자 수만큼 만들고, `data-tab`과 패널 `id`를 맞춘다.
4. 개요 탭: 인자 요약 카드 → 인자끼리 차이 → 공통 정보 → 출처 표.
5. 인자 탭: 2-3 표의 순서대로 소제목을 만들고, 문서 내용을 5장 부품으로 옮긴다.
6. 점수 단계 색을 정한다: 등급(A~D)이면 `gA~gD`, 등급이 아닌 3단계면 `u1~u3`, 판정 결과면 `gA/gC/gD`, 우리 설계·제외는 `gX`.
7. 그림표 데이터는 문서의 숫자를 그대로 넣는다. 숫자를 새로 만들지 않는다.
8. 바닥글에 출처 문서와 날짜를 적는다.
9. 밝은 화면과 어두운 화면, 좁은 화면(폭 375px 정도)에서 한 번씩 열어 본다.

## 10. 지켜야 할 것

- 그룹 화면에는 그 그룹의 인자만 담는다. 다른 그룹의 인자나 전체 비중 표는 넣지 않는다.
- 근거가 없는 숫자·규칙은 "우리 설계"(`pill pX`)나 "팀 판단"(`warn`)으로 표시한다.
- 원문을 직접 확인하지 못한 자료는 그렇다고 적는다 (예: "원문 미확인", "검색 결과 요약으로 확인").
- 색은 3장 이름표의 변수(`var(--…)`)로만 쓴다. 색 코드를 직접 적지 않는다 (예외: `.pill`·`.gcard`의 흰 글자).
