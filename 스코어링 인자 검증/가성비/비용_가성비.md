# 비용: 가성비

작성일: 2026-11-23
상태: 계산식·비교 순서·점수 구간 확정

## 1. 계산식

```
1. 내 값:        ㎡당 환산 임대료 = (월세 + 보증금 × 1%) ÷ 전용면적
2. 비교 그룹:    같은 동 + 같은 층 구간 + 같은 연식 구간 + 같은 면적 구간인 매물 (내 매물은 뺌)
                 10건 미만이면 3장의 순서대로 조건을 풀거나 지역을 넓힘
3. 배율:         배율 = 내 ㎡당 환산 임대료 ÷ 비교 그룹의 ㎡당 환산 임대료 중앙값
4. 점수:         0.5배 이하 100점, 1.0배 50점, 1.5배 25점, 1.75배 이상 0점
                 기준점 사이는 선형 보간
```

- 단위는 만원이다. 관리비와 부가가치세는 넣지 않는다.
- 배율이 1보다 작으면 비슷한 매물보다 싸고, 1보다 크면 비싸다.
- 점수의 뜻: "비슷한 조건의 가게들과 비교해 ㎡당 얼마나 싼 편인가."

## 2. 비교 조건 (구간)

| 조건 | 구간 |
|---|---|
| 지역 | 같은 동에서 시작 (동은 항상 구+동으로 묶음. 예: 달서구 도원동과 중구 도원동은 다른 동) |
| 층 | 지하 / 1층 / 2층 / 3층 이상 |
| 연식 | 10년 미만 / 10∼15년 / 15∼20년 / 20∼25년 / 25∼30년 / 30년 이상 (사용승인일부터 매물 확인일까지의 경과년수) |
| 면적 | 전용면적 33㎡ 미만 / 33∼66㎡ / 66∼99㎡ / 99∼132㎡ / 132㎡ 이상 |

- 층이 "전체층" 또는 "기타(저/중/고/전체층)"인 매물은 건물 전체 층수(1층∼N층)의 중앙값을 그 매물의 층으로 본다. 0.5로 끝나면 올림한다(2층 건물 → 2층, 3층 건물 → 2층, 4층 건물 → 3층).

## 3. 비교 순서

각 단계에서 비교 매물(내 매물 제외)이 **10건 이상**이면 그 단계의 중앙값으로 배율을 구하고 멈춘다. 10건 미만이면 다음 단계로 넘어간다.

### 3-1. 지상 매물 (1층 / 2층 / 3층 이상)

| 단계 | 비교 대상 | 매물 수 (2,638건 중) |
|---|---|---|
| ① | 같은 동 + 층·연식·면적 | 227 |
| ② | 같은 동 + 층·연식 (면적 뺌) | 603 |
| ③ | 같은 구 + 층·연식·면적 | 912 |
| ④ | 같은 구 + 층·연식 (면적 뺌) | 616 |
| ⑤ | 같은 구 + 연식 (면적·층 뺌) | 201 |
| ⑥ | 같은 구 전체 (조건 모두 뺌) | 79 |

### 3-2. 지하 매물

| 단계 | 비교 대상 | 매물 수 (66건 중) |
|---|---|---|
| ① | 같은 동 + 지하·연식·면적 | 0 |
| ② | 같은 동 + 지하·연식 | 0 |
| ③ | 같은 구 + 지하·연식·면적 | 0 |
| ④ | 같은 구 + 지하·연식 | 11 |
| ⑤ | 대구 전체 + 지하·연식·면적 | 21 |
| ⑥ | 대구 전체 + 지하·연식 | 15 |
| ⑦ | 같은 구 + 지하 | 11 |
| ⑧ | 대구 전체 + 지하 | 8 |

- 지하 ①∼③은 지금 데이터에서 0건이지만, 지상과 틀을 맞추고 매물이 늘어날 때를 대비해 둔다.
- 이 순서로 하면 점수를 받지 못하는 매물은 0건이다(지상 2,638건 + 지하 66건 = 2,704건).

### 3-3. 순서를 이렇게 정한 이유 (우리 매물 데이터로 계산)

- 네 조건을 모두 걸면 같은 동에서 10건 이상인 매물은 2,704건 중 227건(8.4%)뿐이고, 같은 구로 넓혀도 1,126건(41.6%)은 10건 미만이다.
- 그래서 **빼도 배율이 덜 바뀌는 조건부터** 하나씩 푼다. 조건을 하나 빼거나 지역을 넓혔을 때 비교 매물 중앙값이 바뀌는 정도는 아래와 같다(변화율의 중앙값).

| 바꾸는 것 | 지상 | 지하 |
|---|---|---|
| 면적 빼기 | 약 5∼6% (같은 동 기준) | 약 16% |
| 층 빼기 | 약 7% (같은 구 기준), 같은 동 안에서는 0∼15% | (지하는 층을 빼지 않음) |
| 연식 빼기 | 약 26% (같은 구 기준), 같은 동 안에서는 약 14% | 약 157% |
| 동 → 구로 넓히기 | 약 12∼21% | - |
| 구 → 대구 전체로 넓히기 | - | 약 105% |

- **지상:** 면적은 같은 동 안에서 빼도 거의 바뀌지 않아, 구로 넓히기 전에 먼저 뺀다. 층·연식은 같은 동 안에서 빼는 것과 구로 넓히는 것이 비슷하거나 구로 넓히는 쪽이 나아서, 구로 넘어가 지킨다. 연식은 빼면 가장 크게 바뀌므로 마지막까지 지킨다.
- **지하:** 1층 등과 섞으면 지하가 실제보다 싸게 나온다(배율 중앙값 0.58). 그래서 끝까지 지하끼리만 비교한다(0.93). 지하는 연식에 따라 임대료 차이가 매우 커서, 같은 구보다 연식을 먼저 지킨다.

## 4. 점수 구간

| 배율 | 점수 | 우리 매물 중 이 배율 미만 비율 (2,704건) |
|---|---|---|
| 0.5배 이하 | 100 | 7.7% |
| 1.0배 | 50 | 51.3% |
| 1.5배 | 25 | 80.0% |
| 1.75배 이상 | 0 | 88.1% |

- 기준점 사이는 선형 보간한다. 0.5배보다 싸면 100점, 1.75배보다 비싸면 0점으로 고정한다.
- 예: 0.75배 → 75점, 1.25배 → 37.5점, 1.6배 → 15점.
- 1.0배(비슷한 매물과 같은 값)가 0∼100점의 가운데인 50점이다.
- 상·하한을 고정하고 사이를 직선으로 잇는 방식이라, 매물을 갱신해도 같은 배율은 같은 점수를 받는다.

### 4-1. 확인필요

- 매물 정보만으로 점수를 믿을 수 없다고 판단한 매물은 계산에서 빼지 않고, 점수 대신 **"확인필요"**로 표시한다. 어떤 매물이 확인필요인지는 목록으로 알려 준다.
- 지금 확인필요는 2건이다.

| 매물 | 값 | 배율 | 이유 |
|---|---|---|---|
| 2658788057 북구 산격동 1층 전용 61.48㎡ | 보증금 13,500 / 월세 370 | 6.54 | 1층 2개 호실과 2층을 묶은 가격인데 면적은 한 호실 값이라 ㎡당 값이 부풂 |
| 2658789341 북구 산격동 1층 전용 43.2㎡ | 보증금 13,500 / 월세 370 | 9.31 | 위 매물과 같은 묶음의 다른 호실 |

## 5. 계산식의 근거

| 식의 부분 | 근거 자료 | 내용 |
|---|---|---|
| 월세 + 보증금을 환산해 더하기 | 감정평가 실무기준 [670-3.3]④, 한국부동산원 상업용부동산 임대동향조사 | 임대료는 보증금까지 포함한 실질임대료가 원칙. 부동산원 산식 "환산임대료 = (보증금×전환율/12) + 월 임대료" |
| 보증금 × 1% | 상가건물 임대차보호법 시행령 제2조 제3항, 제5조와 법 제12조 | 차임 환산 비율 "1분의 100", 전환 상한 연 12%(= 월 1%) |
| 관리비·부가세 제외 | 한국부동산원 임대동향조사 | 환산임대료에서 관리비와 부가가치세 제외 |
| 비슷한 매물과 비교 | 감정평가에 관한 규칙 제2조 제8호·제22조, 감정평가 실무기준 [400-3.3.2] | 임대사례비교법: 위치적·물적 유사성이 있는 임대사례와 비교 |
| 층 4구간 | 유기용·이재우(2023), 김종근·주승민(2016), 감정평가 실무기준 [610-3.1.3]②, 국세청 건물 기준시가 계산방법 고시 제11조 | 지하/1층/2층/3층 이상으로 나눈 회귀분석, "3층 이상의 효용비율은 유사", 층별 효용 반영 원칙 |
| 연식 6구간 | 국토교통부 2025년 건축물 현황 통계 | 경과년수 10년 미만부터 5년 단위 집계, 30년 이상 = 노후 건축물 |
| 전용면적, 면적 5구간 | 중소벤처기업부 소상공인실태조사 | 사업장 면적(공용면적 제외) 33㎡(10평) 단위 집계 |
| 10건 기준 | IAAO Standard on Ratio Studies (참고) | 판매사례 5건 미만 표본은 신뢰도가 매우 낮음 |
| 점수 방식 (상·하한 고정 + 선형) | COINr 정규화 문서 (EU JRC, 2022) | goalposts 방식 |

원문과 출처 링크는 `가성비 근거자료.md`에 있다.

근거가 없는 부분 (우리 설계)

- 1%는 법정 비율(상한)이지 대구 시장의 실제 전환율이 아니다.
- 비교 순서(지상 6단계, 지하 8단계)는 공식 기준이 아니라 우리 매물 데이터로 정했다(3-3).
- 10건이라는 숫자는 자체 설정이다. IAAO의 5건보다 엄격하게 잡은 값이다.
- 점수 기준점(0.5·1.0·1.5·1.75배)과 점수(100·50·25·0)는 팀 자체 설정이다. "몇 배면 몇 점"을 정한 공식 기준은 찾지 못했다.
- 층 미상 매물을 건물 층수 중앙값으로 정하는 규칙은 우리 설계다.
- 연식·면적을 임대사례비교법의 "물적 유사성"으로 보는 것은 우리 해석이다. 조문에 연식·면적이라는 말은 없다.

## 6. 데이터 처리

- **사용 데이터:** `데모/추가 자료/대구 전체 공실정보/대구_구역별_매물 (최종).csv` (네이버부동산 월세 매물 2,717건, 매물 확인일 2026-10∼11월)
- **중복:** 동·층·전용면적·보증금·월세가 같고, 좌표 100m 이내이며 사용승인일 차이가 62일 이내(좌표가 없으면 사용승인일이 같음)인 쌍은 같은 매물로 보고 하나만 남긴다. 남길 매물은 ① 빈칸 아닌 항목이 많은 쪽 → ② 확인일이 늦은 쪽 → ③ 매물번호가 큰 쪽(나중에 올라온 매물). 지금 13쌍.
- **사용승인일 형식:** 연월만 있으면(예: 199012) 그달 1일, 연도만 있으면(예: 1985) 그해 7월 1일로 본다. 확인일보다 늦은 사용승인일(신축 예정)은 경과 0년(10년 미만).
- **사무실 2건·지식산업센터 1건:** 포함한다.
- **계산 대상:** 2,717 − 중복 13 = **2,704건** (지상 2,638건, 지하 66건). 층 미상 26건은 건물 층수 중앙값으로 층을 정해 포함(1층 2, 2층 16, 3층 이상 8).

## 8. 한계

- **매물 가격은 호가다.** 계약가가 아니고, 시점수정도 하지 않는다. 매물 확인일은 2026-10∼11월이다.
- **감정평가액이 아니다.** 임대사례비교법의 사례 선택 기준만 참고했고, 사정보정·시점수정·가치형성요인 비교는 하지 않는 상대 지표다.
- **늦은 단계일수록 비교가 느슨하다.** 지상 ⑥단계(79건)와 지하 ⑦·⑧단계(19건)는 층·연식 등이 빠진 비교다.
- **대구 전체 비교는 동네 차이를 반영하지 못한다.** 지하 ⑤·⑥·⑧단계(44건)가 해당한다.
- **지하는 표본이 작다.** 66건으로 잰 영향 수치는 크게 나왔을 수 있다.
- **층 영향은 작게 잡혔을 수 있다.** 지상의 "층 빼기 약 7%"는 비교 매물이 많은 그룹(대부분 1층)으로 잰 값이다. 층별 임대료 차이 자체를 부정하는 결과가 아니다.
- **층을 추정한 매물이 있다.** 층 미상 26건에는 "통임대", "건물전체 임대"처럼 여러 층을 함께 빌려주는 매물이 섞여 있어, 단일 층 매물과의 비교는 정확하지 않을 수 있다. 이 26건은 1.5배 이상이 10건으로, 전체보다 비율이 높다.
- **전용면적 값이 계약면적일 수 있다.** 매물의 전용면적과 공급면적이 같은 경우가 많아(1,751건), 중개사가 계약면적을 적은 매물이 섞여 있을 수 있다.
- **1% 비율은 법정 상한이다.** 한국은행 기준금리 × 4.5배가 12%보다 낮아지면(기준금리 2.67% 미만) 법정 상한이 달라진다. 2026-11-18 기준금리 3.00%에서는 12%가 상한이다.
- **값이 많이 튀는 매물 28건(사분위 범위 3배 밖)은 아직 하나씩 보지 않았다.** 지금 확인필요는 직접 확인한 4건 중 2건이다.
