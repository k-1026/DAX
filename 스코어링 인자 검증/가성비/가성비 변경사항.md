# 가성비 변경사항

작성일: 2026-11-23
기존 기준(`v2.대구 공실 스코어링 설계(11.16 버전).html`의 가성비 인자)과 새 기준이 달라진 내용만 모았다.
새 기준 자체의 설명은 `비용_가성비.md`, 근거 원문은 `가성비 근거자료.md`에 있다.

## 1. 무엇을 바꿨나

| | 기존 | 변경 |
|---|---|---|
| 내 값 | ㎡당 월세 = 월세 ÷ 전용면적 | ㎡당 환산 임대료 = (월세 + 보증금 × 1%) ÷ 전용면적 |
| 보증금 | 식에 없음 | 월 1%로 환산해 월세에 더함 |
| 비교 조건 | 같은 동 + 층대 | 같은 동 + 층 + 연식 + 면적 |
| 층 구분 | 1층 / 그 외 (2구간) | 지하 / 1층 / 2층 / 3층 이상 (4구간) |
| 연식 구분 | 없음 | 10년 미만 / 10∼15년 / 15∼20년 / 20∼25년 / 25∼30년 / 30년 이상 (사용승인일 기준, 매물 확인일 시점) |
| 면적 구분 | 없음 | 전용면적 33㎡ 미만 / 33∼66㎡ / 66∼99㎡ / 99∼132㎡ / 132㎡ 이상 |
| 표본이 모자랄 때 | 같은 동·층대가 10건 미만이면 같은 구·층대 | 10건 이상 모일 때까지 단계별로 조건을 풀거나 지역을 넓힘. 지상 6단계, 지하 8단계 |
| 지하 매물 | 1층이 아닌 층대("그 외")에 섞여 비교 | 끝까지 지하끼리만 비교. 같은 구에서 모자라면 대구 전체 지하끼리 |
| 비교 그룹에 자기 자신 | 포함 | 제외 |
| 점수 구간 | 0.5배 100 · 1.0배 60 · 1.5배 20 · 1.75배+ 0 | 0.5배 이하 100 · 1.0배 50 · 1.5배 25 · 1.75배 이상 0 |
| 사이 값 | 선형 보간 | 선형 보간 (같음) |
| 층이 "전체층·기타"인 매물 (26건) | 처리 규칙 없음 (1층이 아니면 "그 외") | 건물 전체 층수의 중앙값(0.5는 올림)을 그 매물의 층으로 봄 |
| 같은 매물이 두 번 올라온 경우 | 처리 없음 | 같은 매물로 보이는 13쌍은 하나만 남김 |
| 점수를 믿을 수 없는 매물 | 처리 없음 | 점수 대신 "확인필요"로 표시하고 목록으로 알림 (지금 2건) |

| 단계 | 비교 대상 |
|---|---|
| ① | 같은 동 + 층·연식·면적 |
| ② | 같은 동 + 층·연식 |
| ③ | 같은 구 + 층·연식·면적 |
| ④ | 같은 구 + 층·연식 |
| ⑤ | 같은 구 + 연식 |
| ⑥ | 같은 구 전체 |

지하 매물:

| 단계 | 비교 대상 |
|---|---|
| ① | 같은 동 + 지하·연식·면적 |
| ② | 같은 동 + 지하·연식 |
| ③ | 같은 구 + 지하·연식·면적 |
| ④ | 같은 구 + 지하·연식 |
| ⑤ | 대구 전체 + 지하·연식·면적 |

| ⑦ | 같은 구 + 지하 |
| ⑧ | 대구 전체 + 지하 |

## 2. 바꾼 이유

- **보증금을 넣은 이유:** 기존 식은 월세만 봐서, 보증금이 큰 매물과 작은 매물이 같은 값으로 비교됐다. 임대료 감정평가 원칙(실질임대료)과 한국부동산원 통계는 보증금을 월세로 환산해 더한다.
- **층을 4구간으로 나눈 이유:** 기존 "그 외"에는 2층, 3층 이상, 지하가 섞여 있었다. 연구와 통계에서 2층, 3층 이상, 지하는 임대료·가격 수준이 서로 다르다.
- **연식·면적 조건을 넣은 이유:** 같은 동·같은 층이어도 신축과 30년 넘은 건물, 작은 가게와 큰 가게의 ㎡당 임대료가 다르다. 우리 매물로 재 보니, 같은 구 기준으로 연식 조건을 빼면 배율이 약 26% 바뀌었다.
- **비교 순서를 단계별로 바꾼 이유:** 네 조건을 모두 걸면 같은 동에서 10건 이상 모이는 매물이 8.4%뿐이고, 같은 구로 넓혀도 41.6%는 10건 미만이다. "점수 비우기"나 "대구 전체로 비교"보다, 빼도 값이 덜 바뀌는 조건부터 하나씩 푸는 방식이 모든 매물에 점수를 주면서 비교를 덜 흐트러뜨렸다.
- **지하를 따로 다룬 이유:** 지하는 대구 전체에 66건뿐이다. 1층 등과 섞어 비교하면 배율 중앙값이 0.58로 나와, 실제로 싸서가 아니라 비교 상대 때문에 가성비가 좋아 보였다. 지하끼리 비교하면 0.93이다.
- **자기 자신을 뺀 이유:** 내 값이 비교 기준(중앙값)에 섞이면, 표본이 적을 때 배율이 1 쪽으로 끌려간다.
- **점수 구간을 바꾼 이유:** 비슷한 매물과 같은 값(1.0배)을 0∼100점의 가운데인 50점에 두었다. 기존 구간(1.0배 60점)에는 인용할 근거가 없었다.
- **층 미상 26건을 넣은 이유:** 매물 자료에 실제 층이 없어 그대로 두면 층 구간을 정할 수 없다. 빼는 대신 건물 층수의 중앙값으로 정해 점수를 받게 했다.
- **"확인필요"를 둔 이유:** 여러 호실을 묶은 가격에 한 호실 면적만 적힌 매물처럼, 매물 정보만으로는 ㎡당 값이 부풀어 점수를 믿을 수 없는 경우가 있었다. 계산에서 빼지 않고 표시만 다르게 한다.

## 3. 기존에서 이어받은 것

- 비슷한 매물의 **중앙값** 대비 **배율**로 가성비를 보는 방식
- 분모를 **전용면적**으로 쓰는 것
- 같은 동에서 시작하고, 표본이 **10건** 미만이면 넓히는 기준
- 동에서 모자라면 같은 **구**로 넓히는 방향
- 점수 기준점의 배율 위치(**0.5 · 1.0 · 1.5 · 1.75배**)와 양 끝 점수(0.5배 이하 100점, 1.75배 이상 0점)
- 기준점 사이를 **선형 보간**하는 방식
- 1층을 따로 비교하는 것 (기존 근거: 1층 단가 1.6만/㎡가 2층 이상 1.0만/㎡보다 60% 비쌈)

## 4. 기존에 있었는데 새 기준에서 자리가 없어진 것

- **층대 "그 외" 하나로 묶기:** 2층·3층 이상·지하로 나뉘었다.
- **"동·층대 표본 10건 이상이 79%" 근거:** 조건이 늘어나 더 이상 맞지 않는다. 새 기준의 표본 수는 `비용_가성비.md` 3-3에 있다.
- **"나머지는 구·층대(최소 69건)" 처리:** 단계별 비교 순서로 바뀌었다.
- **1.0배 60점, 1.5배 20점:** 50점, 25점으로 바뀌었다.
