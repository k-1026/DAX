## 지금 계산식 (초안 0번 요약)

- ㎡당 환산 임대료 = (월세 + 보증금 × 1%) ÷ 전용면적
- 비교 조건: 같은 동 + 층(지하 / 1층 / 2층 / 3층 이상) + 연식(10년 미만 / 10∼15 / 15∼20 / 20∼25 / 25∼30 / 30년 이상) + 면적(33㎡ 미만 / 33∼66 / 66∼99 / 99∼132 / 132㎡ 이상)
- 비교 매물이 10건 미만이면 본문 7의 순서대로 조건을 풀거나 지역을 넓힘 (지상 6단계, 지하 8단계)
- 배율 = 내 ㎡당 환산 임대료 ÷ 비교 매물 중앙값
