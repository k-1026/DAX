# 용도 일치도 변경사항

작성일: 2026-11-23
기존 기준(`scoring_engine.py`의 `USE_SCORE`·`use_match`, `classify_use.py`의 분류 규칙, `스코어링 모델 구축 설계.md` 3-1장)과 새 기준이 달라진 내용만 모았다.
새 기준 자체의 설명은 `업종 적합_용도 일치도.md`, 근거는 `용도 일치도 근거자료.md`에 있다.

## 1. 무엇을 바꿨나

점수 단계를 4개에서 3개로 줄이고, 경계 업종 두 가지의 배정을 바꿨다.

| | 기존 | 변경 |
|---|---|---|
| 점수 단계 수 | 4개 (명시 / 다용도 / 다른 업종만 / 신호 없음) | 3개 (명시 / 다용도 / 그 밖) |
| 명시 (고른 업종이 적혀 있음) | 100 | 100 |
| 다용도 (명시가 아니고 다용도 표시가 있음) | 60 | 50 |
| 다른 업종만 (8개 업종 중 다른 업종만 적힘) | 30 | 25 ("그 밖"으로 합침) |
| 신호 없음 (빈칸, `(선택)안함` 등) | 50 | 25 ("그 밖"으로 합침) |
| 8업종 밖 말만 있음 (약국, 창고 등) | 신호 없음으로 50 | 25 ("그 밖") |
| 범용어만 있음 (프랜차이즈, 상가 등) | 신호 없음으로 50 | 25 ("그 밖") |
| 음악·악기·댄스·보컬 연습실 | 8업종 밖 (놀이·여가) | 공연문화 |
| 점핑 (점핑다이어트 등) | 교육 (발레와 같은 줄) | 운동시설 |

## 2. 바꾼 이유

- 점수값(100·60·50·30)을 정해 주는 외부 공식 기준이 없었다. 토지 적합성 평가나 GIS 적합성 분석도 "순서 단계를 나누고 숫자는 분석자가 붙이는" 방식까지만 정해 준다.
- 데이터로 확인된 순서는 "명시가 맨 위"(층 일치도 89.5 > 그 업종 언급이 없는 쌍 73.0) 하나뿐이었다. 다용도 > 신호 없음 > 다른 업종만의 순서는 확인되지 않았다.
- 그래서 "고른 업종이 적혔나 → 다용도인가 → 둘 다 아님"의 세 단계로 단순하게 보기로 했다. 다른 업종만 적힌 매물과 아무것도 안 적힌 매물을 나눌 근거가 없었다.
- 기존에는 약국·창고처럼 8업종 밖 말만 적힌 매물이 "다른 업종을 추천했는데도" 신호 없음 50점을 받아, 다른 업종만 적힌 매물(30점)보다 점수가 높았다. 세 단계로 합치면서 이 어긋남이 없어졌다.
- 신호 없음 533건(19.6%)을 결측으로 빼고 남은 인자로 다시 나눌지 정해야 했다. 결측으로 빼지 않고 "그 밖" 25점을 주기로 했다.
- 연습실: 단독 "연습실"·"댄스"는 이미 공연문화인데, "음악 연습실", "댄스 연습실"처럼 붙여 쓰면 8업종 밖으로 가서 어긋났다. 건축법 시행령 [별표 1]에는 연습실이 따로 없다.
- 점핑: 실제 매물 문구가 "점핑다이어트"로 운동 프로그램이다. 별표1로 보면 체력단련장(제2종 근린생활시설 파목) 쪽이다.

## 3. 기존에서 이어받은 것

- **판정 순서:** 고른 업종 말 → 다용도 표시 → 그 밖. 그래서 "카페 네일 등 다용도"처럼 다른 업종과 다용도가 같이 적힌 매물은 학원을 골라도 다용도 50점이다.
- **업종 목록 만드는 법:** 추천용도 칸과 특징 칸을 따로 분류한 뒤 합친다.
- **어느 칸에 적혔든 명시 100점:** 특징 칸의 추천 문장·업종 나열·단독 언급도 추천용도 칸과 같다.
- **업종을 여러 개 나열해도 명시 100점.**
- **세부 업종을 골라도 대분류 기준:** 배달전문을 골라도 "커피"만 적힌 매물은 식음료 명시 100점이다.
- **분류 절차와 키워드 사전:** 정규화 → 합성어 먼저 → 특징 칸 위치 설명 지우기 → 키워드 매칭. 위 두 경계 업종 말고는 키워드·합성어·다용도·범용어·비정보 사전을 그대로 쓴다.
- **그대로 둔 경계 업종:** 마사지(뷰티), 공방·작업실(공연문화), 키즈카페(8업종 밖), 동물병원·어린이집(8업종 밖), 스터디카페·독서실(교육), 쇼핑몰(사무업무), 자동차·가구 전시장(소매), 당구·골프연습장(운동시설), 요양병원(의료), 의료기기·보청기(소매).

## 4. 정했지만 점수에 넣지 않은 것

- **약국 → 소매:** 별표1 제1종 근린생활시설 가목의 소매점에 "의약품"이 들어 있어 소매로 결정했다. 다만 기록만 두고 점수에는 넣지 않았다. 넣으면 매물 13건이 소매를 얻는다.
- **넓은 키워드 오탐:** 넓은 말 하나만으로 업종이 붙은 180쌍을 모두 읽었더니 틀림이 18쌍(명시 3,626쌍의 0.5%)이었다. 가장 큰 구멍은 소매의 `매장`(가게 일반 뜻, 12쌍)이다. 오탐이 적어서 키워드 사전은 바꾸지 않았다.

## 6. 함께 고쳐야 하는 곳

이 문서의 변경은 아직 코드에 반영하지 않았다(2026-11-23).

- `scoring_engine.py` 105행 `USE_SCORE`: `{"명시": 100, "다용도": 50, "신호없음": 25, "타업종만": 25}`로 바꾼다. `use_match`(260∼267행)는 그대로 둬도 결과가 같다.
- `classify_use.py` `COMPOUND` 62행: `(음악|악기|댄스|보컬)\s*연습실`을 `기타:놀이·여가` 줄에서 떼어 `공연문화`로 보낸다. 노래연습장·노래방·PC방·게임방·만화는 밖에 둔다.
- `classify_use.py` `COMPOUND` 71행: `발레|점핑\S*`를 나눠 `발레`는 교육, `점핑\S*`는 운동시설로 보낸다.
- `스코어링 모델 구축 설계.md` 3-1장 "신호 강도와 용도 일치도" 표와 v2 HTML의 용도 일치도 행: 점수값(100·60·50·30)을 새 점수로 바꾼다.
- 점수값이 바뀌므로, 용도 일치도 점수로 계산한 그룹 안 비중 후보(CRITIC)는 다시 계산해야 한다.
- 참고: `classify_use.py` 머리말 7∼8행의 "엔진 반영은 팀 결정 후"는 이미 엔진에 반영된 지금 상태와 다르다. 인용할 때 헷갈리지 않게 적어 둔다.
