# 업종 적합: 용도 일치도

작성일: 2026-11-23
상태: 계산식·점수 방식 확정 (코드에는 아직 반영하지 않음)

## 1. 계산식

```
입력:  사용자가 고른 업종 C (8개 업종 중 하나. 세부 업종을 골라도 그 대분류)

1. 분류하기:   매물의 추천용도 칸과 특징 칸을 따로 업종으로 분류한다
2. 합치기:     두 칸에서 나온 업종을 합쳐 이 매물의 업종 목록을 만든다
               두 칸 중 하나라도 다용도 표시가 있으면 "다용도 표시 있음"
3. 판정:       C가 업종 목록에 있음            → 명시    100
               아니고, 다용도 표시 있음         → 다용도   50
               둘 다 아님                      → 그 밖    25
```

- 위에서부터 검사하고 처음 맞는 조건에서 점수가 정해진다.
- 점수는 매물 × 업종마다 하나다. 같은 매물이라도 사용자가 고른 업종에 따라 점수가 다르다.
- 결측은 없다. 추천용도·특징이 모두 비어 있어도 "그 밖" 25점을 받는다.

## 2. 텍스트를 업종으로 분류하는 방법

`classify_use.py`의 순서를 따른다.

1. **정규화:** 오타·다른 표기를 통일한다 (까페→카페, 샾→샵, 헬쓰→헬스, 맛사지→마사지, 피티→PT샵 등).
2. **합성어 먼저:** 일부가 다른 업종 말인 표현을 먼저 판정하고 본문에서 지운다 (스터디카페→교육, 키즈카페→8업종 밖, 동물병원→8업종 밖, 쇼핑몰→사무업무, 자동차 전시장→소매, 무인카페→식음료 등).
3. **위치 설명 지우기 (특징 칸만):** 매물 주변을 설명하는 말은 업종으로 치지 않는다 ("이마트 옆", "○○병원 앞", "오피스상권", "사무실 많음", "메디컬타워 옆" 등).
4. **업종 키워드 찾기:** 남은 글에서 업종 키워드를 찾는다. 한 매물이 여러 업종에 들어갈 수 있다.
5. **그 밖의 표시:** 다용도 표시, 범용어, 비정보, 8업종 밖 말을 따로 기록한다.

## 3. 점수가 나오는 방식

| 판정 | 점수 | 조건 | 뜻 |
|---|---:|---|---|
| 명시 | 100 | 고른 업종이 추천용도 칸이나 특징 칸에 적혀 있음 | 중개사가 그 업종을 직접 추천함 |
| 다용도 | 50 | 명시가 아니고, 다용도 표시가 있음 | 그 업종도 들어올 수 있게 열어 둠 |
| 그 밖 | 25 | 명시도 다용도도 아님 | 다른 업종만 추천했거나, 아무 정보가 없음 |

## 4. 계산식의 근거

| 식의 부분 | 근거 | 내용 |
|---|---|---|
| 경계 업종을 어느 업종에 넣을지 | 건축법 시행령 [별표 1] 용도별 건축물의 종류 | 헷갈리는 업종은 별표1에서 어느 항목에 있는지를 참고해 배정함 (예: 의료기기는 1종 가목 소매점, 요양병원은 9호 의료시설, 독서실은 2종 타목) |
| 순서 있는 단계를 정하고 숫자를 붙이는 방식 | FAO 토지 적합성 평가 틀, Esri ArcGIS Weighted Overlay | 적합성을 순서 있는 단계로 나누고, 단계마다 붙이는 숫자는 분석자가 정함 |
| "명시"가 가장 높은 점수 | 우리 데이터 (설계 문서 3-1장) | 명시 쌍의 층 일치도 89.5 > 그 업종 언급이 없는 쌍 73.0 |
| 어느 칸에 적혔든, 몇 개를 나열했든 명시 100 | 우리 데이터 (설계 문서 3-1장) | 특징 칸 명시 87.2∼88.8, 추천용도 칸 89.5로 차이 없음. 1개 89.9 · 2개 90.3 · 3개 89.2 · 4개 이상 88.2 |
| 키워드 사전이 잘 작동하는지 | 우리 데이터 (2026-11-23 점검) | 넓은 말 하나만으로 업종이 붙은 180쌍 중 틀림 18쌍 (명시 쌍의 0.5%) |

근거가 없는 부분 (우리 설계)

- 점수값 100·50·25와 그 간격은 팀이 정한 값이다. 이 숫자를 정해 주는 외부 공식 기준은 찾지 못했다.
- 다용도(50)가 그 밖(25)보다 높다는 순서는 데이터로 확인하지 않았다.
- 다른 업종만 적힌 매물과 아무것도 안 적힌 매물을 같은 25점으로 본 것도 팀 판단이다.
- 별표1은 건물 용도를 등록하는 기준이지, 업종끼리 얼마나 비슷한지를 정한 기준이 아니다. 배정의 참고로만 쓴다.

자세한 원문 대조는 `용도 일치도 근거자료.md`에 있다.

## 5. 이 방식의 성질

- 점수는 세 가지뿐이다. 같은 판정이면 같은 점수다.
- 중개사가 업종을 많이 적을수록 명시를 받는 업종이 많아진다. 업종을 몇 개 적었는지로 점수를 깎지 않는다.
- 다용도 표시는 고른 업종이 적혀 있지 않을 때만 쓰인다. 고른 업종이 적혀 있으면 다용도 표시가 있어도 100점이다.
- 특징 칸의 위치 설명("○○병원 앞")은 지운 뒤 분류하므로, 주변 시설 때문에 명시가 되지 않는다.
- 점수의 뜻: "중개사가 이 업종을 추천했는가."

## 6. 경우별 처리

| 경우 | 처리 |
|---|---|
| 추천용도·특징 모두 비어 있음 | 그 밖 25 |
| 추천용도는 비고 특징에만 업종이 있음 | 특징 칸의 업종으로 판정 (명시면 100) |
| 8업종 밖 말만 있음 (약국, 창고, PC방 등) | 그 밖 25 |
| 범용어만 있음 (프랜차이즈, 상가) | 그 밖 25 |
| 다른 업종 + 다용도 | 다용도 50 |
| 고른 업종 + 다용도 | 명시 100 |
| 세부 업종을 고름 (예: 배달전문) | 대분류(식음료) 기준으로 판정. 세부 업종 말("배달")이 없어도 식음료 말이 있으면 명시 100 |

## 7. 한계

- 점수값 100·50·25는 사용자 good/bad 피드백으로 검증되기 전까지는 가설이다. good/bad가 쌓이면 단계별 good 비율로 다시 맞춘다.
- 다른 업종만 적힌 매물과 아무것도 안 적힌 매물이 같은 25점이다. 빈칸이 많은 매물(533건, 19.6%)은 다른 업종을 추천받은 매물과 구별되지 않는다.
- 키워드 오탐이 일부 남아 있다. 소매의 `매장`("프랜차이즈매장", "디저트 매장"처럼 가게 일반 뜻, 12쌍), `의료기`("의료기영업소", 2쌍), 법정 용도명 `업무시설`(2쌍), "메디컬빌딩" 같은 건물 이름 등이다. 명시 쌍의 0.5% 수준이다.
- 위치 설명 지우기는 특징 칸에만 적용된다. 추천용도 칸에 적힌 건물 이름("메디컬빌딩")은 지우지 않는다.
- 세부 업종을 골라도 대분류로 판정하므로, 공연문화에서 스튜디오·연습실을 고르면 "공방"·"작업실"만 적힌 매물(100건)도 명시 100점을 받는다. 이 매물들은 1층 81%·면적 중앙값 49㎡로, 스튜디오·연습실 쪽(1층 16%·153㎡)과 쓰임이 다르다.
- 중개사가 적은 글을 그대로 믿는다. 중개사가 적지 않은 업종이 실제로 맞을 수 있고, 적은 업종이 실제로 맞지 않을 수 있다.

## 8. 재현 방법

`classify_use.py`가 있는 `0.스코어링 최종중/` 폴더에서 실행한다. 아래 코드는 지금 `classify_use.py`(연습실·점핑 변경 전)를 그대로 쓴다.

```python
import csv, sys
sys.path.insert(0, '.')                     # classify_use.py가 있는 폴더
import classify_use as cu

SCORE = {"명시": 100, "다용도": 50, "그 밖": 25}

def judge(rec, fea, cat):
    rc, _, rm, _, _ = cu.classify(rec)                  # 추천용도 칸
    fc, _, fm, _, _ = cu.classify(fea, is_feature=True) # 특징 칸 (위치 설명 지움)
    cats, multi = rc | fc, bool(rm or fm)
    if cat in cats:
        return "명시"
    if multi:
        return "다용도"
    return "그 밖"

rows = list(csv.DictReader(open('../추가 자료/대구 전체 공실정보/대구_구역별_매물 (최종).csv', encoding='utf-8-sig')))
print([(c, SCORE[judge(r, f, c)]) for r, f, c in [
    ("학원, 사무실", "", "교육"),
    ("카페 네일 등 다용도", "", "교육"),
    ("카페, 음식점", "", "교육"),
    ("", "", "교육"),
    ("약국", "", "교육")]])
# [('교육', 100), ('교육', 50), ('교육', 25), ('교육', 25), ('교육', 25)]
pairs = [judge(r["추천용도"], r["특징"], c) for r in rows for c in cu.CATS]
print(len(pairs), {k: pairs.count(k) for k in SCORE}, round(sum(SCORE[k] for k in pairs) / len(pairs), 1))
# 21736 {'명시': 3626, '다용도': 8783, '그 밖': 9327} 47.6
```
