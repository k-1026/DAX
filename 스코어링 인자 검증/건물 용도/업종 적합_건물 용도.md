# 업종 적합: 건물 용도

작성일: 2026-11-25
상태: 판정 규칙·점수 확정 (이 폴더의 복사본 코드 `scripts/building_use.py`에 반영. 원본 브랜치 코드와 결과 파일에는 반영하지 않음)

## 1. 계산 흐름

```
입력:  매물 하나 (좌표, 층, 전체층, 전용면적, 사용승인일, 건물명),  사용자가 고른 업종 C (8개 중 하나)

1. 건물 찾기:     매물 좌표가 들어 있는 필지(연속지적도)의 건축물대장을 쓴다           → 점포함
                 그 필지에 건물이 없으면 반경 30m 안에서 건물이 있는 가장 가까운 필지 → 근사
                 고른 건물이 사용승인일·층수 둘 다 틀리면, 30m 안 이웃 필지에서
                 사용승인일이 맞고 대조 점수가 더 높은 건물로 바꾼다                    → 검증보정
2. 동 고르기:     한 필지에 건물(동)이 여러 개면 사용승인일 → 전체층 → 건물명이 맞는 동,
                 그래도 여럿이면 주거동이 아닌 동, 그래도 여럿이면 연면적이 가장 큰 동
3. 신뢰도:        사용승인일·층수·건물명을 대장과 대조해 높음 / 보통 / 확인필요
4. 층 줄 고르기:  고른 동의 층별개요에서 매물 층의 줄을 고른다 (3장)
5. 등급:          고른 줄의 용도 코드 × 업종 C × 전용면적 → A / B / C / D (4장)
6. 점수:          A 100 · B 80 · C 40 · D 30.  매칭신뢰도가 확인필요면 이 인자는 비운다
```

- 점수는 매물 × 업종마다 하나다. 같은 매물이라도 사용자가 고른 업종에 따라 등급이 다르다.
- 등급을 정하는 것은 고른 줄의 **용도 코드 앞 두 자리**(용도 대분류)다. 기타용도 글자는 단지 내 상가인지 가릴 때와 공용 공간 줄인지 가릴 때만 본다.
- 건축물대장은 두 부분으로 되어 있다.
  - 표제부: 건물(동)마다 한 장. 주용도, 지상·지하 층수, 사용승인일, 연면적
  - 층별개요: 층마다 여러 줄. 줄마다 층, 용도 코드·명칭, 기타용도, 면적

## 2. 매칭 신뢰도

### 2-1. 대조 항목

| 항목 | 일치 | 불일치 | 비교불가 |
|---|---|---|---|
| 사용승인일 | 매물과 대장 날짜가 같거나 **1일 이내** 차이(근접일치). 매물이 연월만 있으면 같은 달 | 그 밖 | 둘 중 하나가 없거나 형식이 다름 |
| 층수 | 매물 전체층 = 대장 지상층수 | 다름 | 둘 중 하나가 없음 |
| 건물명 | 한쪽 이름이 다른 쪽에 들어 있음 (공백·기호 무시) | 다름 | 둘 중 하나가 없음 |

### 2-2. 신뢰도

| 신뢰도 | 조건 | 건물 용도 인자 |
|---|---|---|
| 높음 | 맞는 항목이 하나 이상이고 틀린 항목이 없음 | 사용 |
| 보통 | 맞는 항목과 틀린 항목이 섞여 있거나, 모두 비교불가 | 사용 |
| 확인필요 | 틀린 항목만 있음 | **제외** |

아래 경우는 대조 결과와 상관없이 **확인필요**로 내려 인자에서 뺀다.

| 경우 | 이유 | 건수 |
|---|---|---:|
| 고른 동에 매물 층 줄이 없고 같은 필지의 다른 동에만 있음 | 매물이 어느 동인지 대장으로 확인할 수 없음 | 10 |
| 용도 코드가 공백·b0, 또는 Z3·Z6·Z8이 아닌 Z 코드 | 대장 용도를 알 수 없음 | 8 |
| 공동주택(02) 코드 줄인데 기타용도가 공용 공간 (단지 내 상가 낱말 없음) | 계단실 줄을 주택으로 볼 근거가 없음 | 7 |
| 단지 내 상가인데 같은 층 상가 줄을 못 찾았고, 고른 줄 기타용도가 공용 공간 | 매물 칸이 상가인지 대장만으로 알 수 없음 | 5 |
| 매물이 지하층인데 대장에 그 지하층 줄이 없음 | 대장에 없는 공간의 용도를 추정하게 됨 | 3 |

- 공용 공간 낱말: 계단, 기계실, 경비실, 주차, 대피, 로비, 보일러, 전기실, 발전기, 수위실, 관리실, 관리사무, 승강기, 엘리베이터, 홀, 복도, 물탱크, 저수조, 펌프, 피트, 공조, 화장실, 방재, 변전, 통신실, 램프, 덕트, 옥탑, 설비실, MDF, EPS, 창고 (`COMMON_SPACE_WORDS`)
- 건수는 대장과 연결된 2,664건에서 대조 결과로 확인필요가 된 179건을 뺀 뒤, 위에서부터 처음 걸린 조건으로 센 것이다. 확인필요는 모두 212건이다.

## 3. 층 줄 고르기

### 3-1. 일반 매물

| 순서 | 상황 | 고르는 줄 | 판정기준 표시 | 점수에 쓰는 매물 |
|---|---|---|---|---:|
| 1 | 매물 층이 "전체층", "저층·중층·고층" 등 | 줄 대신 **표제부 건물 주용도** | 건물주용도(층정보없음) | 25 |
| 2 | 고른 동에 매물 층 줄이 없음 | (확인필요, 2-2) | 해당층없음 / 다른동만있음 | 0 |
| 3 | 매물 층 줄이 하나 | 그 줄 | 해당층 | 1,840 |
| 4 | 줄이 여러 개인데 용도 대분류가 모두 같음 | 그중 면적이 매물 전용면적과 가장 비슷한 줄 (어느 줄이든 등급은 같음) | 해당층_용도여러개_같은분류 | 218 |
| 5 | 줄이 여러 개이고 대분류가 다름 | 매물 전용면적과 면적이 가장 비슷한 줄 | 해당층_용도여러개_면적근접선택 | 360 |

- 같은 층에 주택 줄과 주택이 아닌 줄이 섞여 있으면 주택 줄은 후보에서 뺀다(매물은 모두 상가로 내놓은 것이므로).
- 층 정보가 없어 건물 주용도로 판정한 매물은 근거 화면에 **"층 정보가 없어 건물 주용도로 판정"**이라고 표시한다.

### 3-2. 아파트 단지 내 상가

대장에서 단지 상가는 공동주택 코드(02001 아파트, 02004 생활편익시설, 02005 부대시설, 02006 복리시설)로 등록되는 일이 많다. 코드만 보면 주거용도 D가 되므로 아래 순서로 따로 처리한다.

```
1. 단지 내 상가인지:  고른 줄의 용도 코드가 02(공동주택)이고,
                     용도 명칭·기타용도에 생활편익시설·부대시설·복리시설·근린생활시설·상가·판매시설·점포 중 하나가 있음
2. 상가 줄 찾기:      같은 동·같은 층 줄 중 용도 코드가 주택(01·02)이 아니고 공용 공간도 아닌 줄
3. 판정:              상가 줄의 용도 대분류가 하나 → 그중 면적이 가장 큰 줄로 일반 매물과 같이 판정   (판정기준: 단지내상가_같은층상가줄)
                     상가 줄이 없거나 대분류가 둘 이상 → 고른 줄의 기타용도가 공용 공간이면 확인필요, 아니면 8업종 모두 B
```

- 2번의 "공용 공간"은 기타용도에 공용 공간 낱말이 있고 점포 종류를 뜻하는 말(세탁, 소매, 음식, 의원, 미용, 이용, 제과, 다방, 사무소, 학원, 약국, 슈퍼, 점포)이 없는 줄이다. 쓰레기·재활용·휴게공간은 항상 공용 공간으로 본다. 예: "생활시설(세탁소, 화장실)"은 화장실이 있어도 세탁소가 있어 상가 줄이다.
- 단독주택(01) 코드는 단지 내 상가로 보지 않는다. 상가주택의 주택 층은 주거용도 D다.
- B의 사유 문구는 "공동주택 단지 내 상가: 근린생활시설 종류가 적혀 있지 않아 판정 불가"다.

| 결과 | 점수에 쓰는 매물 |
|---|---:|
| 같은 층 상가 줄로 업종별 판정 | 9 |
| 8업종 모두 B | 37 |

## 4. 등급

### 4-1. 등급의 뜻과 점수

| 등급 | 점수 | 뜻 | 입점까지 필요한 절차 |
|---|---:|---|---|
| A | 100 | 등록 용도 그대로 입점 가능 | 없음 |
| B | 80 | 같은 근린생활시설군 안에서 바꾸면 됨, 또는 업종 일부만 가능 | 제1종 ↔ 제2종 근생 변경. 대부분 신청도 필요 없고, 의원·학원·공연장 등으로 바꿀 때만 건축물대장 기재내용 변경 신청 |
| C | 40 | 다른 시설군이라 용도변경 필요 | 하위군으로는 용도변경 신고, 상위군으로는 허가. 변경 용도의 건축기준·부설주차장 기준 충족 |
| D | 30 | 주거용도 (단독·공동주택) | 주거업무시설군 → 근린생활시설군이라 용도변경 허가 |

## 5. 계산식의 근거

| 규칙 | 근거 | 내용 |
|---|---|---|
| 등록 용도별 업종 (A가 되는 용도) | 건축법 시행령 [별표 1] | 제1종 근생 소매점·휴게음식점·미용원·의원 등, 제2종 근생 일반음식점·학원·체력단련장·사무소·공연장 등 |
| 면적 기준 (300·500·1,000·30㎡) | 별표 1 제3호·제4호 | "같은 건축물에 해당 용도로 쓰는 바닥면적의 합계"가 기준 이하일 때만 근생 |
| 전용면적으로 면적 기준을 대신함 | 별표 1 비고 2 | 건축물 내부를 구분해 독립적으로 쓰면 구분된 면적 단위로 산정 |
| A / B / C를 가르는 선 | 건축법 제19조, 시행령 제14조 제5항 | 같은 시설군 안은 기재내용 변경, 다른 시설군은 신고(하위군)·허가(상위군) |
| B 대부분은 신청도 필요 없음 | 시행령 제14조 제4항 | 제1종·제2종 근생 상호 변경은 기재내용 변경 신청을 하지 않아도 됨 (의원·학원·공연장 등으로 가는 경우는 제외) |
| 고시원 C | 시행령 제14조 제5항 제5호 라목 | 제2종 근생 중 다중생활시설은 영업시설군 |
| 위락시설 식음료 C | 별표 1 제16호, 시행령 제14조 제5항 | 위락시설에 일반·휴게음식점이 없고, 위락시설은 문화집회시설군 |
| 주거 D | 건축법 제19조 제2항, 시행령 제14조 제5항 | 주거업무시설군(8) → 근린생활시설군(7)은 상위군 변경 허가 |
| C·D 공통 부담 | 주차장법 시행령 제6조 제4항 | 용도변경 시 주차대수 차이만큼 부설주차장 추가 (사용승인 5년 지난 1천㎡ 미만 건물은 면제) |
| 단지 내 상가를 근생 규칙으로 판정 | 주택법 시행령 제7조, 공동주택관리법 시행령 별표 3 | 단지 상가는 복리시설이고, 근생 사이 변경은 건축법 절차를 따름 |
| 사용승인일 1일 | 우리 데이터 + 팀 판단 | 날짜가 같으면 층수 일치율 94%, 1~62일 차이는 55~65%. 중개사는 공적 자료를 보고 기재하므로 단순 오기만 허용 |
| 반경 30m | 우리 데이터 | 거리 구간(0~10·10~20·20~30m)별 층수 일치율이 81~83%(근사), 94~97%(검증보정)로 거의 같음 |
| 확인필요만 제외 | 우리 데이터 | 별도 점검에서 보통(99%·97%)이 높음(99%·99%)과 비슷하고 확인필요(79%·85%)와 다름 |

근거가 없는 부분 (우리 설계)

- 점수값 100·80·40·30은 비용·기간 자료로 계산한 값이 아니다. 등급 사이 간격(A-B 20, B-C 40, C-D 10)을 법 절차의 차이(같은 시설군 안 / 시설군 변경 신고·허가 / 같은 허가)에 맞춘 판단값이다.
- C 안에 하위군 신고(예: 판매시설 → 근생)와 상위군 허가(예: 업무시설 → 근생)가 섞여 있다. 업무시설 → 근생은 주택 → 근생(D)과 같은 허가 절차인데 C다.
- B 안의 신청 필요 여부(5업종 불필요, 3업종 기재내용 변경 신청)를 점수에 반영하지 않는다.
- 사용승인일 1일은 업무 관행에 근거한 팀 판단이다. 네이버 부동산의 사용승인일 입력 방식(직접 기재인지 대장 연동인지)은 공식 자료로 확인하지 못했다.
- 공용 공간 낱말 목록과 단지 내 상가 낱말 목록은 데이터를 보고 정한 것이다.

자세한 원문 대조와 데이터 분석은 `건물 용도 근거자료.md`에 있다.

## 7. 이 방식의 성질

- 점수는 네 가지뿐이다. 같은 등록 용도·같은 면적 구간이면 같은 점수다.
- 업종 안에서 대부분의 매물이 A(100)와 B(80)로 나뉜다. C·D는 업종마다 12~15%다.
- 등급은 대장 등록 용도 기준이다. 실제로 그 용도로 쓰이고 있는지, 중개사가 어떤 업종을 추천했는지는 보지 않는다.
- 점수의 뜻: "건축물대장상 이 칸에 이 업종이 바로 들어갈 수 있는가, 들어가려면 어떤 절차가 필요한가."

## 9. 한계

- 면적 기준을 매물 전용면적으로 근사한다. 같은 임차인이 여러 칸을 같은 용도로 쓰거나(별표 1 비고 2 나목), 다른 임차인과 같은 업종으로 연계해 쓰면(다목) 법은 합산하지만 매물 데이터로는 알 수 없다.
- 일반 건물에서는 같은 층에 줄이 여러 개면 면적이 가장 비슷한 줄을 고른다. 층별개요의 상가 줄은 그 층 상가 전체를 합친 면적이라, 면적이 작은 계단실·경비실 줄이 뽑힐 수 있다.
- 대장과 중개사 글이 다른 매물이 있다(예: 글은 "제1종 근생", 대장은 주택). 대장만 보고 판정하므로 용도변경 후 대장이 갱신되지 않았다면 틀린다.
- 건물 통임대 매물은 매물 층에 가장 낮은 층만 적혀 그 층 줄로 판정된다. 전체에 몇 건인지 확인하지 않았다.
- 분양 계약의 업종 제한(같은 상가 안 동종 업종 금지)은 대장으로 알 수 없어 반영하지 않는다.
- 용도지역 제한(국토계획법)은 매물별 용도지역 데이터가 없어 반영하지 않는다. 일반주거지역의 업무시설·제2종 근생 허용 범위는 대구광역시 도시계획 조례에 달려 있다.
- 점수값 100·80·40·30은 사용자 good/bad 피드백으로 검증되기 전까지는 가설이다.
- 실제 입점 가능 여부는 관할 구청 건축과 확인이 필요하다. 건물 용도 판정은 참고용이다.

## 10. 재현 방법

`건물 용도/` 폴더에서 실행한다. 저장된 건축물대장 원본과 `건물용도_v1.csv`의 PNU(건물 매칭 결과)를 쓰므로 API 키가 필요 없다. 아래 코드는 `scripts/building_use.py`의 함수를 판정 단계(`main()` 4단계)와 같은 순서로 부른다.

```python
import csv, json, os, sys, collections
sys.path.insert(0, 'scripts')                       # 건물 용도/scripts/building_use.py
import building_use as bu

D = '../../11.13을 위한 발표자료/혜림언니꺼/혜숭씨 data'
BLD = D + '/08.외부데이터/05_건축물대장'          # 저장된 건축물대장 원본 (<PNU>.json)
lis = {r['매물번호']: r for r in csv.DictReader(open(D + '/07.대구_매물유형별_csv/대구_구역별_매물 (최종).csv', encoding='utf-8-sig'))}
pnu = {r['매물번호']: r['PNU'] for r in csv.DictReader(open(D + '/09.스코어링/건물용도_v1.csv', encoding='utf-8-sig'))}
nm = lambda x: (x.get('mainPurpsCdNm') or '') + ' ' + (x.get('etcPurps') or '')

cnt = collections.defaultdict(collections.Counter); used = 0
for no, p in pnu.items():
    L = lis[no]
    if not p or not os.path.exists(f'{BLD}/{p}.json'): continue
    rec = json.load(open(f'{BLD}/{p}.json', encoding='utf-8'))
    if not rec.get('title'): continue
    t, _ = bu.choose_building(rec['title'], L)                          # 2. 동 고르기
    st, _ = bu.verify(t, L)                                             # 3. 신뢰도
    ok = sum(v in ('일치', '근접일치') for v in st.values()); bad = sum(v == '불일치' for v in st.values())
    conf = '높음' if ok >= 1 and bad == 0 else ('확인필요' if bad >= 1 and ok == 0 else '보통')
    area, pf = float(L['전용면적'] or 0), bu.parse_floor(L['층'])
    fx, how = bu.pick_floor(rec['floors'], t, pf, area); common = False  # 4. 층 줄 고르기
    if fx and str(fx.get('mainPurpsCd', ''))[:2] == '02':
        if any(w in nm(fx) for w in bu.WELFARE):                       # 단지 내 상가
            shop = bu.pick_apt_shop_row(rec['floors'], t, pf)
            if shop is not None: fx = shop
            else: common = any(w in (fx.get('etcPurps') or '') for w in bu.COMMON_SPACE_WORDS)
        else:                                                           # 공동주택 공용 공간 줄
            common = any(w in (fx.get('etcPurps') or '') for w in bu.COMMON_SPACE_WORDS)
    src = fx or t; code = str(src.get('mainPurpsCd', ''))[:2]
    if (bu.is_unknown_group(code) or common or (not fx and how == '다른동만있음')
            or (not fx and how == '해당층없음' and pf and pf[0] == '지하')):
        conf = '확인필요'
    if conf == '확인필요': continue
    used += 1
    for c in bu.CATEGORIES:                                             # 5. 등급
        cnt[c][bu.judge(c, code, area, nm(src))[0]] += 1

print(used)
for c in bu.CATEGORIES: print(c, [cnt[c][g] for g in 'ABCD'])
# 2452
# 식음료 [987, 1132, 260, 73]
# 소매 [1115, 1035, 229, 73]
# 뷰티 [1084, 1035, 260, 73]
# 공연문화 [986, 1098, 295, 73]
# 사무업무 [1118, 1046, 215, 73]
# 교육 [1060, 1098, 221, 73]
# 의료 [1090, 1035, 254, 73]
# 운동시설 [989, 1098, 292, 73]
```

- 건물 매칭(1단계)까지 처음부터 다시 하려면 `py -I scripts/building_use.py`를 실행한다. 브이월드·건축HUB API 키(`data/.env`의 `VWORLD_API_KEY`, `VWORLD_DOMAIN`, `BLD_API_KEY`)가 필요하다.
