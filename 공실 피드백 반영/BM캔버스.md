# 대구 빈 상가 찾기 · BM 캔버스

임차인 편에서 "내 업종이 되는 상가"를 찾아 주고, 지자체·중개사·임차인 구독으로 운영한다. 같은 내용의 16:9 화면용 파일은 `BM캔버스.html`이다.

## 9개 칸

### 1. 고객

| 구분 | 누구 |
|---|---|
| 쓰는 사람 | 대구에서 가게 자리를 찾는 임차인 (50대 퇴직자 첫 창업, 20~30대 청년 창업) |
| 돈 내는 고객 | 대구시·구청·공공기관 / 공인중개사 / 임차인(단기 구독) |
| 다음 단계 | 오래 빈 상가의 건물주 |

### 2. 가치 제안

| 대상 | 주는 가치 |
|---|---|
| 임차인 | "내 업종이 되는 건물인가"를 계약 전에 알려 줌 / 시세 대비 가격으로 비싼지 싼지 판단 / 빈 정보와 단점을 숨기지 않음 / 큰 글씨, 쉬운 말, 평·걸어서 몇 분 / 대구 특화거리·지원사업 안내 |
| 지자체·기관 | 공실 해소 사업에 쓰는 매칭 도구, 상담 창구용 화면 |
| 중개사 | 질문을 준비해 온 손님, 상담용 성적표·비교표 |

### 3. 채널

- 창업 지원 기관: 소상공인 센터, 창업·퇴직자 교육
- 검색·SNS: "대구 상가 임대" 검색, 인스타그램·유튜브
- 대구시 공공 채널: 시·구청 누리집, 상권 활성화 사업 안내

### 4. 고객 관계

- 가입 없이 무료로 찾기 시작
- 담은 상가는 다시 와도 남음
- 중개사 질문 목록으로 상담까지 동행
- 👍/👎 평가가 다음 추천에 반영
- 판단은 사람에게: 구청·중개사 확인 안내

### 5. 수입

| 수입원 | 내용 | 미정 |
|---|---|---|
| ① 임차인 단기 구독 | **무료**: 추천 상위 5곳, 점수, 좋은 점·확인할 점 / **체험**: 처음 7일은 모든 기능 / **이용권**: 전체 순위, 조건 바꿔 다시 찾기, 나란히 비교, 엑셀, 중개사 질문 목록, 점수 성적표 | 가격, 이용권 기간, 체험 일수(7일은 임시값) |
| ② 지자체·공공기관 용역 | 공실 해소 사업의 도구로 운영 계약. 기관을 통해 온 임차인은 이용권 무료(기관이 대신 부담) | 계약 형태와 금액 |
| ③ 중개사 구독 | 상담 도구(성적표·비교표·건물 용도 확인) + 매물 정보 보강(관리비·권리금 등 빈칸 채우기) | 가격 |

임차인 구독의 무료·유료 선은 사용자가 "제안 3개를 적절히 섞어 보라"고 해서 Claude가 섞어 제안한 것이다. 세 제안은 ① 찾기는 무료·결정 도구는 유료 ② 상위 몇 곳만 무료 ③ 기간 무료 체험 뒤 유료였다.

### 6. 핵심 자원

- 매물 2,717건 + 공공데이터 5종을 묶은 데이터
- 업종 8개별 점수 엔진
- 건축물대장 층별 용도 매칭
- 쉬운 말 설명 규칙 (50대도 읽는 화면)
- 쌓이는 👍/👎 평가

### 7. 핵심 활동

- 매물을 주 1회 모으고 검증
- 건축물대장과 연결해 업종 가능 여부 판정
- 점수 기준 관리, 평가 반영
- 특화거리·지원사업 목록 갱신
- 기관·중개사 협력

### 8. 핵심 파트너

| 파트너 | 역할 |
|---|---|
| 대구시·구청, 대구전통시장진흥재단 | 공실 사업과 연결, 지원사업 목록 제공 |
| 소상공인 지원 기관, 창업·퇴직자 교육 | 상담 창구에서 서비스 안내 |
| 공인중개사 | 매물의 빈 정보를 채움, 계약 단계 이어받음 |
| 공공데이터 제공처 | 건축물대장(국토교통부), 인구·사업체(통계청), 상가 정보(소상공인시장진흥공단), 지도(브이월드) |
| 매물 출처 | 지금은 네이버 부동산 수집. 정식 제휴나 중개사 직접 등록으로 바꿔야 함 (미정) |

### 9. 비용

- 데이터: 매물 수집·검증, 서버, 지도
- 사람: 개발·운영, 특화거리·지원사업 목록 관리, 기관 협력 담당
- AI 사용료: 대화형 상담 기능을 붙이면 발생
- 금액은 아직 계산하지 않음 (미정)

## 지키는 원칙

돈을 내도 매물의 점수와 순위는 바뀌지 않는다. 중개사가 정보를 채우면 "정보 부족" 표시만 사라지고, 확인할 점은 그대로 보인다.

## 아직 확인 못 한 것

| 항목 | 왜 중요한가 |
|---|---|
| 임차인이 실제로 돈을 낼지 | 지금 매물 사이트는 임차인에게 무료다. 단기 구독의 지불 의사를 조사한 적이 없다 |
| 중개사가 실제로 돈을 낼지 | 이미 매물 사이트에 광고비를 내고 있다. 추가로 낼 이유를 확인해야 한다 |
| 매물을 계속 수집해도 되는지 | 지금 데이터는 네이버 부동산에서 수집했다. 돈을 받는 서비스로 운영하려면 출처의 약관과 권리를 확인해야 한다 |
| 비용 규모 | 수입과 비교할 숫자가 없다 |
| 지자체가 계약할지 | 대구시·구청과 이야기해 본 적이 없다 |
