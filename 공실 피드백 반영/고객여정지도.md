# 대구 상가 임차인 고객여정지도

가게 자리를 구하는 두 사람이 결심부터 개업까지 겪는 일과 어려움을 따라가 보고, 서비스가 어디를 풀어야 하는지 찾는다. 같은 내용의 화면용 파일은 `고객여정지도.html`이다.

## 근거 표시

| 표시 | 뜻 |
|---|---|
| 우리 데이터 | 데모 매물 2,717건에서 직접 센 값 |
| 팀 자료 | 「대구 상가 공실, 얼마나 심각하고 어떻게 활용할 것인가」(2026.10.29) |
| 공개 자료 | 조사·보도 |
| 가설 | 아직 확인하지 못한 추정 |

## 주인공 두 사람

| | A. 50대 퇴직자 · 첫 창업 | B. 20~30대 청년 · 첫 창업 |
|---|---|---|
| 누구 | 회사를 그만두고 처음 가게를 내려는 사람 | 적은 자본으로 작게 시작하려는 사람 |
| 걱정 | 퇴직금이 걸려 있어 실패가 가장 두렵다 | 보증금과 월세 부담이 가장 크다 |
| 경험 | 상가 계약을 해 본 적이 없고 서류 용어가 낯설다 | 계약 경험이 없어 조건을 따질 줄 모른다 |
| 디지털 | 작은 글씨와 복잡한 화면이 불편하다 | 검색은 익숙하지만 정보가 너무 많아 고르기 어렵다 |
| 한마디 | "어디가 괜찮은 자리인지, 누구 말을 믿어야 할지 모르겠어요." | "싼 곳은 많은데, 싼 데는 이유가 있을 것 같아 불안해요." |

두 사람의 성격과 감정 높낮이는 가설이다. 실제 임차인 인터뷰로 확인하지 않았다.

## 어려움 8가지

| 어려움 | 단계 | 근거 | 서비스 적용 |
|---|---|---|---|
| P1. 업종에 맞는 자리 기준을 모름 | 결심 | 공개 자료: 60대 신규 자영업자 65.7%가 시작하기 쉬운 업종에 몰림 (한국은행 인용 보도) | 지금 있음: 업종별 점수 기준 |
| P2. 동네 차이를 비교할 방법이 없음 | 동네 알아보기 | 팀 자료: 대구 상권별 중대형 공실률 20.0%(죽전역)~38.3%(서문시장·청라언덕) | 지금 있음: 동네별 지도 / 보완: 공실 흐름 |
| P3. 매물 정보가 비어 있음 | 매물 찾기 | 우리 데이터: 관리비 미기재 61.0%, 추천 용도 비어 있음 25.3%, 건물 전체 층수 전부 미기재 | 지금 있음: 확인할 점 표시 / 보완: 질문 목록 |
| P4. 가격이 적당한지 모름 | 매물 찾기 | 우리 데이터: 같은 동네·비슷한 층 평균보다 20% 넘게 싼 매물 32.5%, 20% 넘게 비싼 매물 32.2% | 지금 있음: 시세 대비 가격 |
| P5. 헛걸음 | 현장 방문 | 우리 데이터: 확인된 지 30일 넘은 매물 12.7% / 헛걸음 경험 자체는 가설 | 지금 있음: 확인일 / 보완: 오래됨 표시 |
| P6. 내 업종이 가능한 건물인지 모름 | 가능 여부 확인 | 우리 데이터: 음식점 기준 서류상 바로 가능 38.3%, 기재 변경 필요 43.9%, 어려움 15.9% / 공개 자료: 위반건축물은 고치기 전까지 용도 변경이 원칙적으로 안 됨 | 지금 있음: 건물 용도 등급, 구청 확인 안내 / 보완: 위반건축물, 토지이음 |
| P7. 계약 조건을 따질 줄 모름 | 계약 | 공개 자료: 서울시 상가임대차 상담 사례 계약 해지 24건, 권리금 23건, 임대료 21건, 관리비 10건 / 팀 자료: 공실 지수 222, 임대료 지수 103 (2020년 1분기=100) | 보완: 상담 준비 질문 / 범위 밖: 법률 판단 |
| P8. 개업 뒤 걱정 | 개업 준비 | 공개 자료: 폐업 이유 1위 매출 부진 70.9%, 폐업 때 빚 보유 68.5% / 팀 자료: 대구 개업 대비 폐업 비율 91.2% (2025) | 범위 밖 / 주변 손님·같은 업종 수 정보만 제공 |

## 두 사람의 차이 (가설)

| 단계 | A (50대) | B (청년) |
|---|---|---|
| 결심 | 익숙한 업종을 고름 | 유행 업종에 끌림 |
| 동네 알아보기 | 지인 말에 기댐 | 온라인 정보가 넘쳐 못 고름 |
| 매물 찾기 | 사이트 사용 자체가 어려움 | 싼 매물만 보다 조건을 놓침 |
| 현장 방문 | 중개사 말에 의존 | 시간이 없어 몇 곳만 봄 |
| 가능 여부 확인 | 용어에서 막힘 | 경험에서 막힘 |
| 계약 | 큰돈이 걸려 겁냄 | 보증금이 모자람 |
| 개업 준비 | 빚 없이 하려다 규모가 작아짐 | 대출 부담이 큼 |

## 여기서 읽히는 것

1. **가장 막막한 곳은 5단계다.** "이 건물에서 내 가게를 할 수 있나"는 일반 매물 사이트가 답해 주지 않는 질문이다. 음식점 기준으로 서류상 바로 가능한 매물은 38.3%뿐이다. 용도 맞춤 추천이 이 자리를 푼다.
2. **매물 정보의 빈칸이 불안을 만든다.** 관리비가 적히지 않은 매물이 61.0%다. 빈칸을 "확인할 점"으로 드러낸 뒤 중개사에게 물어볼 질문으로 바꿔 주는 것이 다음 보완점이다.
3. **6~7단계는 서비스 바깥이다.** 계약서 검토와 개업 뒤 운영은 판단하지 않고, 상담 준비 질문과 "구청·중개사에 확인하세요" 안내로 넘긴다.
