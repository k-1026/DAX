# 2026.11.03 논의 정리 — 콘텐츠에서 데이터 기반 AI 서비스로 피벗

전날까지 만든 "동성로 워크스루 투어"(뮤지컬 체험 콘텐츠) 기획에 대해 받은 피드백을 바탕으로, 방향을 재설계한 내용을 정리합니다.

---

## 1. 받은 피드백

- 뮤지컬 수요와 공간 활용(공실)을 이어주는 통계·데이터가 없고, 지금 만든 건 콘텐츠지 데이터를 이용한 게 아니다
- 공실을 이용한 서비스(예: 스위트스팟)를 만들어야 하는데, 이걸 다 갈아엎어야 한다는 의견도 있었음
- 핵심 지적: 지금 결과물은 "콘텐츠"지 "AI 에이전트"나 "서비스"가 아니다

## 2. 핵심 전환: 공실 용도 추천 AI 에이전트

완전히 갈아엎지는 않고, 기존 리서치(뮤지컬 시장 데이터, 공실 데이터, 도시계획 데이터)는 유지하면서 **"포장"을 바꾸는 방향**으로 재정의했습니다.

**비유**: 넷플릭스가 "내가 본 영화 기록"으로 다음 영화를 추천하듯, 공실의 위치·면적·상권 데이터를 AI에 넣으면 가장 적합한 용도(공연장/카페/전시/사무실 등)를 추천해주는 서비스.

핵심 차이: 사람이 "여기는 뮤지컬 공연장으로 쓰자"라고 콘텐츠를 먼저 정하는 게 아니라, **AI가 데이터를 보고 용도를 스스로 고른다**는 점이 "콘텐츠 아닌 서비스/AI 에이전트"로 인정받을 수 있는 차이입니다.

**참고 실제 사례**:
- 소상공인시장진흥공단 상권정보시스템(sg.sbiz.or.kr) — 주소 입력 시 업종 적합도 분석
- 스위트스팟(sweetspot.kr) — 빈 공간을 팝업스토어 등에 매칭하는 실제 스타트업

## 3. 왜 "공실"이 중심이어야 하는가 (뮤지컬은 여러 후보 용도 중 하나로 낮춤)

| 지표 | 수치 | 출처 |
|---|---|---|
| 동성로 중대형 상가 공실률 | 25.8% (대구 18.9%·전국 14.3% 대비 高) | 한국부동산원 상업용부동산 임대동향조사, 2026Q2 |
| 공실률 지수 vs 임대료 지수 | 222 vs 103 (2020Q1=100) — 공실 2배 이상 증가했지만 임대료는 안 내려감 | 팀 상권 데이터 트랙 |
| 대구 소극장(1~299석) 수 | 94개 (서울 1,006 · 부산 135, 인구 대비 최저) | KOPIS 공연시설 현황정보 |
| DIMF 기간 집중도 | 대구 뮤지컬 공연회차·매출의 80% 이상이 DIMF(6~7월) 기간에 집중 | 월간공연전산망 2026년 8월호 |

이 중 "공실률-임대료 역전"이 시장 실패(market failure)의 핵심 근거이며, 뮤지컬 데이터는 "왜 하필 문화콘텐츠로 채우는가"의 보조 근거로 역할이 바뀝니다.

## 4. 서비스 동작 방식 (3단계)

1. **매칭**: 공실 DB(면적·위치·임대조건) × 공연팀 등 수요자 자동 매칭
2. **단기 계약**: 1~2개월 단위 임대로 부담 제거
3. **데이터 축적**: 매칭 성사율·공실 해소 건수를 누적해 운영 KPI로 활용

## 5. 구현에 필요한 데이터 — 지금 당장 구해야 하는 것

| 종류 | 데이터 | 출처 |
|---|---|---|
| 공실 데이터 | 동성로 실제 빈 상가 위치·면적·공실기간 | 소상공인시장진흥공단 상가(상권)정보(data.go.kr) 또는 현장조사 |
| 상권 데이터 | 유동인구, 임대료 | 상권정보시스템(sg.sbiz.or.kr), 한국부동산원 |
| 수요 데이터 | 뮤지컬 관람률 등 | 기존 확보 완료 (KOPIS·국민문화예술활동조사) |

## 6. 실행 워크플로우 (8단계)

| 단계 | 내용 |
|---|---|
| 1 | 동성로 + 공실 10~20곳으로 범위 좁히기 (전수조사 아님) |
| 2 | 복합쇠퇴지수 기준으로 성공 5곳 + 실패(공실) 5곳 "정답지" 확정 |
| 3 | 정답지 10곳의 면적·유동인구·임대료·경쟁시설 데이터 수집 |
| 4 | 규칙 기반 점수 공식 설계 (가중치는 팀 합의로 초안 작성) |
| 5 | 정답지에 공식 적용 → 백테스팅으로 실제 결과와 비교 |
| 6 | 안 맞는 부분 가중치 조정 (2~3회 반복) |
| 7 | 검증된 공식을 실제 동성로 공실 전체에 적용 |
| 8 | 공실별 적합도 순위를 표·지도로 시각화 |

## 7. 검증 방법: 백테스팅

새로운 실험이나 설문 없이, **이미 일어난 일(이미 성공한 공간, 이미 비어있는 공간)로 모델을 거꾸로 채점**하는 방식입니다.

- 이미 성공한 문화공간(오페라하우스, 콘서트하우스, 김광석길 등)의 입지 특성을 모델에 넣었을 때 "적합도 높음"이 나오는지 확인
- 공실 기간이 긴 곳(도시재생 미수립 지역)을 넣었을 때 "적합도 낮음"이 나오는지 확인
- 예측과 실제 결과가 반복해서 일치하면 모델을 신뢰할 수 있음

## 8. 핵심 발견: 복합쇠퇴지수 — 이미 존재하는 "정답표"

2030 대구도시기본계획(2018, p.196~197)에서 대구시가 이미 쓰고 있는 표준화 통계모델을 확인했습니다.

**복합쇠퇴지수**: 139개 읍면동 전체에 대해 아래 30개 지표를 종합해 등급(-3등급 양호 ~ 3등급 쇠퇴)으로 계산해놓은 공식 지수.

| 분야 | 세부지표(일부) | 개수 |
|---|---|---|
| 인구사회 | 노령화지수, 독거노인가구비율, 기초생활수급자수, 경제활동인구 등 | 10개 |
| 산업·경제 | 사업체 수, 재정자립도, 지가변동률, 총사업체 증감률 등 | 12개 |
| 물리·환경 | 공가율, 노후건축물 비율, 노후주택비율, 공시지가 등 | 8개 |

**이게 5~7번 전체 문제를 한 번에 해결합니다**:
1. 정답지 선정기준 = 복합쇠퇴지수가 이미 계산된 동 (139개 전체)
2. 우선기준 = 지수 등급 자체 (1~3등급=쇠퇴/공실 후보, -1~-3등급=양호/성공사례 후보)
3. 표준화 통계모델 = 새로 설계할 필요 없이 이 지수를 "정답 점수"로 그대로 재사용

**검증 파이프라인**: 우리 AI 예측 점수 ↔ 대구시 복합쇠퇴지수(정답)를 동별로 비교 — 같은 방향으로 움직이면 모델이 현실과 맞는다는 증거.

**원자료 출처**: "2025 대구광역시 도시재생전략계획"(2016.12)에 처음 등장, 최신판은 **"2035 대구광역시 도시재생전략계획"(대구광역시, 2026년)** — 이 최신 원문을 대구광역시/대구도시재생지원센터에서 구하면 법정동별 세부 지수 원자료까지 확보 가능.
