## 목표

대구에서 처음 가게를 여는 사람은 매물은 많은데, 어느 자리가 내 업종에 맞는지 판단할 기준이 없어서 허위매물까지 섞인 목록을 하나하나 직접 찾아다닌다. 이 문제를 **업종을 고르면 그 업종에 맞는 공실을 근거와 함께 순서대로 보여 주는 것**으로 줄인다.
(`중간발표/01_문제_한문장과_병목.md`)

**성공 신호**
1. 추천 점수 순으로 본 매물의 good 비율이 "월세 낮은 순" 기준선보다 높다. 업종별 표본 30건 이상일 때 판정한다. (설계서 12절)
2. bad 사유 중 '정보 오류' 비율이 줄어든다. 확인일 배지의 효과를 보는 지표다. (`고객여정지도/문서_여정지도_원본.md` 3절)

## 사용자

- **주 사용자:** 대구에서 카페 등 가게 창업을 처음 준비하는 임차인. 페르소나는 서연(32세, 카페, 월세 200만 원 이하, 약 40㎡)이다. (`spec/scenario.md`, `BM 캔버스/bm_canvas.md` 1절)
- **보조 사용자:** 없음. 중개사와 공공기관은 사용자·지불자에서 제외했다. (`BM 캔버스/bm_canvas.md` 5절)

## 기능

**필수** (`spec/scenario.md` 2절)
- US-1 업종으로 찾기: 업종 8개 선택, 월세 상한·면적·보증금·구/법정동 필터, 추천 점수 순 목록과 지도
- US-2 점수의 이유 보기: 4그룹 점수, 좋은 점 / 확인할 점, 데이터 없음 표시, 건물 용도 등급
- US-3 매물 신선도 보기: N일 전 확인, 최근 확인 순 정렬, 원본 매물 링크
- US-4 다녀온 뒤 평가 남기기: good/bad + bad 사유 저장

## 제약

- **범위 밖:** 계약·중개·결제는 하지 않는다. 추천까지가 서비스 역할이고, 계약은 사용자가 중개사와 직접 한다. (설계서 1절)
- **실시간 공실 확인 불가:** 매물은 네이버부동산 공개 매물 스냅샷(2,717건)이다. 지금도 공실인지는 확인할 수 없고, 화면에 확인일로만 보여 준다. (`고객여정지도/문서_여정지도_원본.md` 5절)
- **데이터:** 무료·공공데이터만 쓴다. 유료 카드매출과 민간 유동인구는 쓰지 않는다. (설계서 2절)
- **점수 해석:** 점수는 추천 참고 지표이고 임대·창업 성과를 보장하지 않는다. 건물 용도 판정은 참고용이며 입점 가능 여부는 구청 확인이 필요하다. (설계서 14절)
- **추천 제외:** 반영률 60 미만인 매물(좌표 없는 48건 등)은 추천하지 않는다. (설계서 8절)
- **점수와 근거는 구독·회원 여부와 무관하다:** 구독 여부에 따라 점수와 순위가 바뀌지 않고, 점수 근거·좋은 점/확인할 점·확인일·출처는 로그인 없이 모두 볼 수 있다. (`BM 캔버스/bm_canvas.md` 5절, `BM 캔버스/tier_features.md` 원칙)
- **개인정보:** 1단계(데모)에서는 연락처를 받지 않는다. 평가는 브라우저에만 저장하고, 내보낸 파일에도 이름·연락처를 넣지 않는다. 2단계에서 회원가입·메일링을 열 때 수집 항목(이메일, 희망 조건), 목적, 보관 기간, 수신 동의 방식을 먼저 정한다. (설계서 12절, `BM 캔버스/revenue_options.md` 2절, WBS 4.6)
- **키 관리:** API 키는 환경변수(`data/.env`, git 제외)로 두고 코드에 적지 않는다. (설계서 13절)
- **약관 확인 필요:** 네이버부동산 수집과 브이월드 저장 약관은 아직 확인하지 않았다. 팀 밖에 공유하기 전에 확인한다. (`BM 캔버스/revenue_options.md` 2절, 설계서 14절)

## 완료 기준

- [ ] 업종을 고를 때, 시스템은 그 업종의 추천 점수 순 목록을 보여 준다. (US-1)
- [ ] 업종을 바꿀 때, 시스템은 목록의 순서를 바꿔 보여 준다. (US-1)
- [ ] 월세 상한을 넣을 때, 시스템은 월세+관리비가 상한을 넘는 매물을 목록과 지도에서 숨긴다. (US-1)
- [ ] 조건에 맞는 매물이 0건일 때, 시스템은 "조건에 맞는 매물이 없습니다"와 조건을 넓히라는 안내를 보여 준다. (US-1, 예외)
- [ ] 매물을 누를 때, 시스템은 4그룹 점수와 좋은 점 / 확인할 점을 보여 준다. (US-2)
- [ ] 인자 값이 없을 때, 시스템은 그 인자를 "데이터 없음"으로 표시한다. (US-2, 예외)
- [ ] 반영률이 60 미만일 때, 시스템은 그 매물을 추천 목록에서 빼고 "데이터 부족"으로 분류한다. (US-2, 예외 · 11.13 데모 화면에는 이 표시가 없어 확인 필요)
- [ ] 매물 상세를 보여 줄 때, 시스템은 "N일 전 확인된 매물"을 함께 보여 준다. (US-3)
- [ ] "최근 확인된 순"을 고를 때, 시스템은 확인일이 가까운 매물부터 보여 준다. (US-3)
- [ ] "👎 안 맞아요"를 누를 때, 시스템은 사유 5개(월세·조건 / 공간 상태 / 위치 / 업종 입점 / 이미 계약됨)를 여러 개 고르게 한다. (US-4)
- [ ] 평가를 남기고 새로고침할 때, 시스템은 그 평가를 잃지 않는다. (US-4, 예외 · **11.13 데모는 평가를 메모리에만 두어 새로고침하면 사라진다. 저장 추가 결정**)
- [ ] [평가 내보내기]를 누를 때, 시스템은 매물번호·업종·good/bad·사유·추천 점수·순위·정렬·평가 시각이 담긴 파일을 내려받게 한다. (US-4)
