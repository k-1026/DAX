# 대구 빈 상가 찾기 · 서브에이전트 구성

상담 에이전트 1개가 사용자와 대화하고, 그 아래 서브에이전트 5개가 일을 나눠 맡습니다.

## 표시 구분

| 구분 | 뜻 |
|---|---|
| 대화 중 호출 | 사용자가 물을 때마다 부름 |
| 미리 준비 | 정해진 주기로 돌려 데이터를 쌓아 둠 |
| AI | 말을 알아듣고 풀어 쓰는 일 |
| 규칙 코드 | 정해진 식으로 계산하는 일 |

## 구조

```
사용자 (가게 자리를 찾는 예비 창업자)
        │
상담 에이전트 (오케스트레이터)
  사용자와 대화하며 필요한 서브에이전트를 순서대로 부르고, 결과를 모아 답합니다.
        │
 ┌──────┼──────────┬──────────┬──────────┐
 ①      ②          ③          ④          ⑤
조건   매물 수집   입지·상권   점수·추천   설명·보고
파악   ·검증       분석
```

## 서브에이전트 5개

### ① 조건 파악

- 맡는 일: 사용자의 말을 검색 조건으로 바꿉니다.
- 구분: 대화 중 호출 · AI
- 하위 파트
  - **업종 분류**: "국숫집" → 음식점·카페
  - **조건 뽑기**: 월세, 보증금, 지역, 넓이
  - **되묻기**: 빠진 조건을 한 번에 하나씩 질문

### ② 매물 수집·검증

- 맡는 일: 매물 데이터를 모으고 믿을 수 있게 정리합니다.
- 구분: 미리 준비 · 규칙 코드
- 하위 파트
  - **매물 수집**: 네이버 부동산 공실 매물
  - **정리**: 중복, 계약 끝난 매물 제거
  - **위치 검증**: 좌표와 법정동이 맞는지 확인
  - **건물 서류 연결**: 건축물대장의 층별 용도

### ③ 입지·상권 분석

- 맡는 일: 매물마다 주변 정보를 붙입니다.
- 구분: 미리 준비 · 규칙 코드
- 하위 파트
  - **교통**: 지하철역, 버스정류장 거리
  - **상권**: 주변 가게 수, 같은 업종 수
  - **주변 손님**: 사는 사람, 일하는 사람 수
  - **땅 규제**: 지번이 있으면 토지이음 조회

### ④ 점수·추천

- 맡는 일: 조건에 맞는 상가의 순위를 매깁니다.
- 구분: 대화 중 호출 · 규칙 코드
- 하위 파트
  - **4가지 점수**: 비용, 공간, 위치, 업종 맞춤
  - **중요도 조정**: "싼 게 제일 중요" → 비용 비중 올림
  - **걸러내기**: 정보가 부족한 매물은 순위에서 제외

### ⑤ 설명·보고

- 맡는 일: 결과를 쉬운 말로 전달합니다.
- 구분: 대화 중 호출 · AI
- 하위 파트
  - **좋은 점 / 확인할 점**: 점수를 문장으로 풀어 씀
  - **점수 성적표**: 항목별 실제 값과 좋음·보통·아쉬움
  - **나란히 비교**: 고른 상가를 한 표로
  - **엑셀·상담 요약**: 중개사에게 가져갈 자료

## 한 번의 상담은 이렇게 흘러갑니다

1. **묻기**: "수성구에 월 200 안쪽으로 학원 자리 있을까요?" → 조건 파악 ①이 업종·월세·지역을 뽑습니다.
2. **고르기**: 점수·추천 ④가 미리 준비된 매물(②)과 주변 정보(③)로 순위를 매깁니다.
3. **설명하기**: 설명·보고 ⑤가 상위 상가의 좋은 점과 확인할 점을 쉬운 말로 풀어 줍니다.
4. **다시 묻기**: "더 싼 곳은요?" → 상담 에이전트가 ④와 ⑤만 다시 부릅니다. ②③은 다시 돌리지 않습니다.

## 설계할 때 지킬 세 가지

1. **점수는 AI가 아니라 코드로**: 같은 조건에는 항상 같은 점수가 나와야 하고, 왜 그 점수인지 설명할 수 있어야 합니다. AI는 말 알아듣기(①)와 쉬운 말로 풀기(⑤)에만 씁니다.
2. **설명은 받은 숫자만으로**: 설명·보고 ⑤는 점수와 실제 값(월세, 거리 등)을 받아 문장으로 바꾸기만 합니다. 데이터에 없는 내용은 말하지 않습니다.
3. **확인이 필요한 건 사람에게**: 입점 가능 여부(구청 건축과)와 계약 여부(중개사)는 에이전트가 단정하지 않고 "확인할 점"으로 넘깁니다.

## 나중에 붙일 만한 것

- **⑦ 상담 준비 (AI)**: 고른 상가마다 중개사에게 물어볼 질문 목록(관리비, 권리금, 용도 변경 가능 여부)을 만들어 줍니다. 사용자가 바로 체감하는 기능이라 먼저 붙일 만합니다.
- **⑥ 피드백 학습 (규칙 코드)**: 👍/👎와 "안 맞은 이유"를 모아 중요도와 기준값을 조정합니다. 평가 데이터가 쌓인 뒤에 의미가 있어 2단계로 둡니다.
