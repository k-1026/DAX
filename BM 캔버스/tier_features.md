# 무료·구독 기능 구분 (초안)

> 상태: **초안 · 팀 결정 전**. 확정된 것은 "월 정액", "알림은 구독 기본 혜택", "상위 신규 매물 24시간 선공개", "점수·순위는 구독과 무관"이다. 구독은 1종이다. 담기·비교 한도는 팀 결정이고, 신규 제안은 가정이다.
> 근거: 데모 `26.11.13 데모.html`의 화면 기능, `고객여정지도_페인포인트.md`, `11.13_feedback.md`, `11.13_ppt_contents.md`

## 원칙

- **신뢰와 관련된 것은 모두 무료다.** 점수 근거, 좋은 점·확인할 점, 확인일, 출처, 로드뷰·토지이음 링크, 면책 문구는 구독과 무관하다. 지난 발표 피드백이 점수 의미 설명을 보완하라고 했다 (`11.13_feedback.md`).
- **점수와 순위는 같다.** 구독은 알림과 24시간 먼저 열람만 다르다.
- **필터는 막지 않는다.** 2단계 공실 탐색 불만 중 조건 필터 부족이 97건이다 (`고객여정지도_페인포인트.md`).

## 확인할 점

- 데모 화면 문구에서는 담기·비교 한도 안내를 찾지 못했다. 현재는 한도가 없거나 화면에 보이지 않는 상태다.
- 새 매물 수집·갱신은 네이버 부동산 기준이며, 약관·이용 조건 확인이 필요하다 (`revenue_options.md` 2절).
- 알림용 연락처·희망 조건 저장은 개인정보·동의 범위 확인이 필요하다 (`revenue_options.md` 2절).

## 팀이 정할 것

- 엑셀 열 구성
- 신규 제안(변동 알림, 메모·공유 링크)을 넣을지
- 추가로 넣고 싶은 구독 기능
